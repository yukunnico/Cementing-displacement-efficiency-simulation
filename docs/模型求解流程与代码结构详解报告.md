## 2. 端到端求解流程（以 hu102 为典型）

这是用户最关心的"详细求解流程"。一次完整模拟 7 步：

### 步骤 1：数据加载
```
load_hu102_tailpipe()                          [hu102_tailpipe.py:66]
  → (WellSpec, tuple[FluidSpec,...], PumpingSchedule, ValidationData)
```
- `WellSpec`：井身几何（井径/井斜/居中度剖面、尾管尺寸、鞋深、评价窗口）
- `FluidSpec`：流体物性（密度、流变模型、屈服应力等）
- `PumpingSchedule`：地面泵注序列（各段流体、体积、排量、起止时间）
- `ValidationData`：现场 CBL/施工记录路径（仅用于对比，不参与求解）

### 步骤 2：套管内 1D 输运
```
CasingFlowSolver(enable_gravity=True).run(well_spec, fluids, schedule)   [hu102_tailpipe.py:263-264]
  → CasingFlowResult
      .fronts              各流体前沿到达鞋口的时间
      .cement_end_time_s   水泥浆尾端到达鞋口时刻
      .shoe_timeline       鞋口出流事件时间序列 (ShoeTimeline)
      .pipe_cross_section_m2
```
解析体积推进法 + 重力沉降修正 + 可选轴向弥散（详见 §4）。

### 步骤 3：鞋口桥接（边界转换）
```
build_coupled_annulus_inlet_provider(casing_result, casing_solver, fluids)  [hu102_tailpipe.py:265]
  → inlet_provider: Callable[[float], AnnulusInletState]
```
把 1D 结果转成"给定地面累计时间 → 返回该时刻环空入口相分数+排量"的函数。

### 步骤 4：确定环空停止时间
```
annulus_stop_time_s(casing_result=casing_result, fluids=fluids)   [hu102_tailpipe.py:266]
  → total_t: float
```
策略因井而异：
- hu101 / hu102：`casing_result.cement_end_time_s`（水泥尾端到鞋口即停）
- ht1_004：找水泥之后第一个非水泥流体到达鞋口的时间（多段水泥浆场景更精确）`[ht1_004_tailpipe.py:153-175]`

### 步骤 5：环空 2D 顶替求解（核心）
```
AnnulusD2DGASolver(total_t=total_t, nz=500).run(well_spec, fluids, inlet_provider)  [hu102_tailpipe.py:70-71]
  → AnnulusSimulationResult
```
时间循环在 solver 内部，runner 不感知。诊断指标（效率/窜槽/混浆/失稳）在 `run()` 内部完成（`annulus_d2dga.py:835-852`）。详见 §6。

### 步骤 6：诊断指标计算
已在步骤 5 内部完成，结果落在 `result.metrics` / `result.depth_profiles` / `result.summary["最终结果"]`。

### 步骤 7：结果导出（`run_and_export` 内，按顺序）`[hu102_tailpipe.py:74-138]`
| 顺序 | 输出 | 函数 |
|------|------|------|
| 7a | 时间序列 CSV | `result.metrics.to_csv()` |
| 7b | JSON 摘要 | 含 `summary` + 流体来源符合性检查 |
| 7c | Markdown 摘要 | 人工可读 |
| 7d | 静态图 4 张 | `plot_time_series` / `plot_depth_profiles` / `plot_risk_indices` / `plot_efficiency_summary_bar` |
| 7e | 参考图集 | `export_reference_figure_set` |
| 7f | 云图 3 类 | `plot_depth_time_contour` / `plot_annulus_snapshots` / `plot_final_fields_contour` |
| 7g | NPZ 场数据 | 2D 场 + 网格坐标 |
| 7h | GIF 动画 | `animate_cement_field(save_format="gif")` |

## 4. 第 2 层：套管内 1D 输运 `cemdisp/transport1d/`

### 4.1 实际实现模式

代码**不以 A/B/C 线性切换**，而是以**模式 B（体积推进）为主干**，通过开关叠加修正：

| 形态 | 开关 | 对应方案 |
|------|------|----------|
| 纯体积推进（活塞流） | 全关 | 模式 B 退化 / 模式 A |
| + 重力沉降修正 | `enable_gravity=True`（默认） | 模式 B 增强 |
| + 轴向弥散 | `enable_axial_dispersion=True`（默认） | 模式 C（Taylor-Aris） |
| 重力+弥散 | 两者同开 | B+C 叠加 |

### 4.2 核心类 `CasingFlowSolver` (`casing_flow.py:87-864`)

```python
CasingFlowSolver(*, dt=2.0, enable_gravity=True, g_constant=9.81,
    settling_velocity_factor=0.0015, enable_axial_dispersion=True,
    dispersion_alpha=0.25, gelation_time_s=600.0, gelation_max_factor=0.95)

.run(well_spec, fluids, schedule) -> CasingFlowResult
.pipe_exit_state_at(result, time_s) -> PipeExitState
```

**数值方法**：
- **无显式网格**，解析体积推进：`distance = cumulative_volume / pipe_area`（`casing_flow.py:191`）
- **无显式时间积分循环**，一次性解析所有前缘到达时间；`dt` 仅用于容差与弥散最小宽度
- **重力修正**（`_gravity_corrected_arrival_time`, `:606-660`）：密度差 + 井斜角投影 `max(cos(inc),0)` + 屈服应力抑制
- **弥散**（`_compute_dispersion_coefficient`, `:277-316`）：牛顿 `D_eff=U²R²/(192·D_mol)`（Taylor 1953/Aris 1956）；幂律 `k_factor=48n+144`；Bingham/HB `D_eff=α·U·R`。在 FRONT_ARRIVAL 事件附近用 erf 生成 5 个 S 形过渡子事件
- **停泵沉降**（`_settled_exit_fluid_name_enhanced`, `:741-807`）：凝胶强度指数发展 + 屈服应力抑制

### 4.3 关键数据结构

- `PipeExitState` (`pipe_exit_state.py:23`)：`(time_s, flow_rate_m3_s, stage_name, phase_fractions)`
- `ShoeTimeline` (`shoe_timeline.py`)：`ShoeEvent` 列表（FRONT_ARRIVAL/REAR_EXIT/RATE_SWITCH/SHUTDOWN/RESTART/END），`.at(time_s)` 线性扫描查最近过去事件
- `CasingFlowResult` (`casing_flow.py:56`)：含 `fronts / shoe_timeline / cement_end_time_s / pumping_end_time_s`

### 4.4 输出接口（传给第 3 层）
```
CasingFlowResult.shoe_timeline  →  boundary_bridge.build_coupled_annulus_inlet_provider()
CasingFlowResult.cement_end_time_s  →  runner 的 annulus_stop_time_s()
```

## 6. 第 4 层：环空 2D D2DGA 核心（最关键）

### 6.1 D2DGA 是什么

**D2DGA** 全称推测为 **Dispersion 2D Gap-Averaged**（二维间隙平均弥散模型），源自 **Zhang & Frigaard (2022), JFM Vol.947, A32** 的环空层流顶替理论框架。

### 6.2 控制方程与求解域

实际求解**四相纯对流方程**（扩散由 D2DGA 通量放大 + 小系数拉普拉斯平滑替代）：
```
∂c_k/∂t + ∇⋅(u·c_k) = 0,  k ∈ {lead, tail, spacer};   c_mud = 1 - Σc_k
w_d2dga = w × f_amp(c_cement, m),   v_d2dga = v × f_amp(c_cement, m)
```
时间推进用**半拉格朗日反演追踪**（`_bilinear_interp`, `annulus_d2dga.py:88-108`）。

**网格**：方位角 θ（`ny`，y∈[0,π·r_mean]，宽边 φ=0 到窄边 φ=1）× 轴向 s（`nz`，鞋口 s=0 向下）。solver 默认 `ny=40, nz=140`，**生产 runner 覆盖为 nz=500**。

### 6.3 偏心环空几何展开（`_build_geom`, `:236-312`）
1. 从 WellSpec 插值井径/井斜/居中度/尾管外径
2. 偏心度 `e = clip(1 - standoff, 0.05, 0.55)` (`:278`)
3. 半间隙均值 `half_gap_mean = (hole - od_mm)/2000` (`:280`)
4. 局部半间隙 `H(φ,s) = half_gap_mean(s) × (1 + e(s)·cos(πφ))` (`:289`)
5. 体积校正：缩放 H 使网格体积 = 物理环空体积 (`:305`)

### 6.4 速度场（`_compute_velocity`, `:509-634`）
Zhang & Frigaard (2022) Hele-Shaw 风格，非解 Navier-Stokes：
1. 基础流动度 `base = (b/b_mean)² / μ_reg`（宽边主导）
2. 浮力修正形状 `buoyancy_shape = 1 + density_contrast × e × (2φ-1)`
3. 轴向速度 `w = q_half × pref / Σ(pref·b·dy)`（截面排量约束）
4. 横向速度 `v` 由连续性 `∂(bw)/∂s + ∂(bv)/∂y ≈ 0` 数值积分

## 7. ⭐ "三闭包"详解（git 提交核心）

"三闭包"指 **R1/R2/R3 三个物理耦合机制**，依次叠加在 R0 基线之上。消融级别定义在 `runners/ht1_004_ablation.py:42-47`：

| 级别 | `enable_d2dga_auto_m` | `enable_d2dga_i3_flux` | `enable_true_buoyancy` | 含义 |
|------|:-:|:-:|:-:|------|
| R0 | off | off | off | 基线：常数 m + 代理浮力 + 无 I3 |
| R1 | **on** | off | off | + 局部黏度比场 |
| R2 | on | **on** | off | + 浮力弥散通量 I3 |
| R3 | on | on | **on** | + 真浮力体力（全开） |

三个开关均默认 `True`（即生产默认 R3 全开），均位于 `AnnulusD2DGASolver.__init__`（`annulus_d2dga.py:192-194`）。

### 7.1 R1：auto-m 黏度比场闭包
- **物理**：速度场浮力修正的 density_contrast 从全局常数（R0/R1/R2）改为局部混合物密度场（R3），使宽边/窄边速度分配随局部水泥浓度实时变化。
- **实现**（`_compute_props`, `:459-471`）：`m_field = μ_mud(γ̇)/max(μ_cement(γ̇),1e-6)`，裁剪 `[0.1,10.0]`。`run()` 中 `enable_d2dga_auto_m=True` 时 `m_for_amp=m_field`（数组），否则用标量 `d2dga_viscosity_ratio`（默认 1.0）(`:733-736`)。

### 7.2 R2：I3 浮力弥散通量闭包
- **物理**：速度场浮力修正的 density_contrast 从全局常数（R0/R1/R2）改为局部混合物密度场（R3），使宽边/窄边速度分配随局部水泥浓度实时变化。
- **公式**（`d2dga_flux.py:119-138`）：`q_buoy = (Δρ·H³/(6η2))·I3(c̄,m)·[-f_xi, f_phi]`
- **I3 函数**（`:85-116`）：`I3 = c̄²(1-c̄)³[4m·c̄+3(1-c̄)] / {2m[m·c̄³+1-c̄³]}`，c̄=0 或 1 时为 0，≈0.5 处达峰。
- **实现**（`annulus_d2dga.py:764-795`）：算散度 `div_q`，`lead -= flux_strength·div_q·lead_frac·dt`，`flux_strength=0.05` 数值稳定限幅 (`:791`)。

### 7.3 R3：真浮力修正闭包（局部密度场，非体力向量）
- **物理**：速度场浮力修正的 density_contrast 从全局常数（R0/R1/R2）改为局部混合物密度场（R3），使宽边/窄边速度分配随局部水泥浓度实时变化。
- **⚠️ 体力向量当前为死代码**：_buoyancy_force_vector（annulus_d2dga.py:474）虽被调用计算 f_phi/f_xi，但 annulus_d2dga.py:603 注释明确"真浮力体力向量当前未注入流动度，保留接口供未来动量源耦合"。其结果实际只用于 R2 的 I3 通量方向因子，不直接作用于速度场。R3 真正生效路径：局部密度场 -> density_contrast -> buoyancy_shape -> pref -> 轴向速度 w。
- **实现**（`_compute_velocity`, `:599-616`）：R3 开 → `density_contrast=(ρ_local-ρ_mud)` 用局部场；R3 关 → `(ρ_cement-ρ_mud)/ρ_mud` 全局常数。

### 7.4 d2dga_flux.py 三个纯函数
| 函数 | 公式 | 位置 |
|------|------|------|
| `d2dga_flux_amplification(c,m)` | `f=[m·c²+1.5(1-c²)]/[m·c³+(1-c³)]`，c∈[0.01,0.99]，f∈[0.5,2.0] | `:44-82` |
| `d2dga_dispersion_function_I3(c̄,m)` | 见上 | `:85-116` |
| `d2dga_buoyancy_flux(c̄,m,Δρ,H,η2,f_phi,f_xi)` | 见上 | `:119-138` |

### 8.2 诊断指标（`run()` 内 `:835-852`）
- 前缘：`front_wide/narrow/mid`（浓度≥0.5 的最远深度）
- 窜槽指数 `channeling = |front_wide-front_narrow|/s_max` (`:847`)
- 混浆指数 `mixing = ∫b·4c(1-c)dyds / half_volume` (`:848`)
- 失稳指数 `instability = 1-exp(-channeling·(mobility_wide/narrow-1)·(1+0.4·mixing)/decay_scale)` (`:851-852`)
- 顶替效率 `effective_efficiency = ∫b·cement dyds / half_volume` (`:838`)

### 8.4 ⚠️ 当前未实现/占位的物理机制（修改切入点）
- **壁面泥饼 `wall` 场恒为零**（`:680`），`wall_field` 存于结果但未参与求解 → 接入泥饼清除模型的入口

## 12. 重构建议（基于代码现状）

1. **抽取 runner 公共基类**：8 个 per-well runner 的 `run_and_export()` 代码重复率极高，`common.py` 目前几乎未被使用（仅一个 `export_old_vs_new_inlet_comparison` 且无人调用）。建议把 5 步流水线 + 导出链抽到 `common.py` 的工厂/基类，per-well runner 只提供 loader + 井名 + 停时策略。这是最高价值的重构点。
2. **`docs/code_file_guide.md` 应重写或删除**：当前内容误导（描述已不存在的筛选模型），与本报告冲突。
3. **CSV→loader 自动加载未实现**：模板齐全但 loader 仍硬编码。若要多井快速接入，应实现 CSV 读取。
4. **质量守恒容差 25% 偏松**：建议按井分层容差或收紧。
5. **`wall` 场恒零、温度/凝胶占位未接**：是明显的功能缺口，也是论文外的扩展方向。
