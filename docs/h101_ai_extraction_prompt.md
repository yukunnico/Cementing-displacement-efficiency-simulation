# 呼101资料数据抽取提示词（供其他 AI 模型使用）

你现在的任务是：**从指定文件夹中的全部资料里，系统提取固井顶替效率模型所需的数据**，并输出一份结构化的数据抽取结果。

## 一、资料路径

请处理以下目录中的全部文件：

`D:\users\desktop\research\控压固井项目\参考文档\呼101`

重点文件包括但不限于：

## 二、抽取目标

请只围绕 **“固井顶替过程与最终水泥浆顶替效率模型”** 所需数据进行抽取。

重点提取以下 6 类数据：

### 1. 几何与井段数据
- 井深
- 固井井段顶部/底部
- 套管/尾管尺寸
- 井眼尺寸
- 环空容积
- 返高
- 井斜 / 轨迹
- 扶正器 / 居中器布置
- 偏心相关信息

### 2. 流体物性数据
- 泥浆密度
- 隔离液密度
- 水泥浆密度（领浆/尾浆分别提取）
- 泥浆流变参数
- 隔离液流变参数
- 水泥浆流变参数
- 屈服值 / YP / 屈服应力
- 幂律或 Herschel-Bulkley 参数（如 `n, K, τy`）

### 3. 施工工况数据
- 排量 / 泵率
- 环空流速
- 分阶段施工顺序
- 各阶段体积
- 压力 / 井口压力 / ECD
- 套管旋转 / 上提 / 下放（如果有）

### 4. 实验与相容性数据
- 稠化时间
- 失水
- 强度
- 静胶凝
- 污染实验
- 相容性实验

### 5. 质量评价 / 校核数据
- 顶替效率模拟结果
- 平均顶替效率
- 局部低效率井段
- 现场评价结论
- 固井质量问题分析

### 6. 模型边界与风险数据
- 压力窗口
- 漏失风险
- 施工限制条件
- 最敏感井段/深度

## 三、特别要求

### 1. 图片/扫描页必须识别
如果 PDF 中有：
- 图片
- 图表
- 扫描页
- 曲线页
- 表格截图

也必须尽量提取其中的数据或工程结论。

尤其要关注：
- 顶替效率模拟图
- 排量变化图
- 压力变化图
- 井口压力图
- 居中度/扶正图
- 稠化曲线
- 静胶凝曲线
- 污染实验图

### 2. 严禁编造数据
如果某个值看不清、无法确认、OCR 不稳定：
- 必须明确标记为 **“不确定”** 或 **“未可靠识别”**
- 不能凭经验补数

### 3. 要区分三种状态
每条数据都要标记为以下之一：

- **直接可读**：文本或表格中可直接读取
- **图像/图表识别**：从图片、曲线、扫描页中识别
- **缺失**：当前资料中未找到

## 四、输出格式要求

请按下面结构输出：

# 1. 文件优先级结论
- 哪几个文件最重要
- 每个文件主要提供什么类型的数据

# 2. 高置信度数据表
按类别分别列出：
- 几何与井段数据
- 流体物性数据
- 施工工况数据
- 实验与相容性数据
- 质量评价数据

推荐表格格式：

| 类别 | 数据项 | 数值 | 单位 | 来源文件 | 页码/位置 | 置信度 | 备注 |
|---|---|---:|---|---|---|---|---|

# 3. 图像/扫描页补充结果
单独列出：
- 从图表中补出来的数值
- 只能提取出的工程结论
- OCR 风险较高但仍有参考价值的数据

# 4. 当前仍缺失的数据
请明确列出缺失项，并说明：
- 为什么缺失
- 缺失后会影响模型的哪一部分

推荐表格格式：

| 缺失项 | 影响模块 | 影响程度 | 建议补充来源 |
|---|---|---|---|

# 5. 建议直接进入模型的数据包

- `mud_density`
- `spacer_density`
- `lead_slurry_density`
- `tail_slurry_density`
- `annular_velocity_168`
- `annular_velocity_139`
- `lead_n`
- `lead_K`
- `tail_n`

并说明每个字段来自哪里。
