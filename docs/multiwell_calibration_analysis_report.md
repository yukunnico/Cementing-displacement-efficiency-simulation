## 5. 是否可以直接做“5井训练 + 1井验证”

### 5.1 结论

**目前不宜直接把“5口井训练、1口井验证”作为可靠的数值回归验证。**

原因不是井数不够，而是：

1. 当前只有 2 口井已经明确有统一口径的数值质量标签。
2. 其余井虽然能提特征，但最终标签并未确认齐全。
3. 即使标签补齐，井级样本数也只有 6，统计自由度极低。
4. 如果把同一井内分段样本拆成训练/验证，会产生明显的数据泄漏，不能当作跨井泛化验证。

### 5.2 当前能做的“原型级验证”

当前更合理的做法是：

1. **数值校准集**：呼101、呼102。
2. **弱监督/排序检查集**：呼探1等仅有定性质量结果的井。
3. **无标签推演集**：呼103、呼探2、呼探1-002（在未补齐标签前，只能做预测区间或风险排序）。

这意味着：

- 现在可以搭出一个**多井分层校准框架的原型**；
- 但不能声称已经完成“6井监督回归模型”的准确率验证。

## 6. 推荐的多井分层 / 回归校准框架

### 6.1 建模定位

当前最适合的不是黑箱强预测模型，而是：

**物理量约束 + 小样本分层校准 + 弱监督标签融合**

### 6.2 三层数据结构

#### A层：强标签井（数值标签）

- 呼101
- 呼102

用途：

- 校准 `α` 或 `η_quality / η_hyd` 的映射关系；
- 校准局部异常因子的有效权重；
- 检验模型对 CBL 代理标签的拟合能力。

#### B层：弱标签井（定性标签）

- 呼探1（当前已见“优/符合率100%”类表述）
- 其余若存在“良好/一般/不合格”总结，也可纳入

用途：

- 只做排序约束；
- 不直接参与数值回归目标的误差计算；
- 用于检查模型输出是否与现场结论方向一致。

#### C层：无标签井

- 呼103
- 呼探2
- 呼探1-002（若最终数值标签仍未补齐）

用途：

- 只作为输入样本做情景推演；
- 输出风险评分、区间预测或待验证预测；
- 不进入监督准确率统计。

### 6.3 统一特征建议

建议统一成如下字段体系：

| 类别 | 字段示例 |
|---|---|
| 井身几何 | 井深、井眼尺寸、套管外径、封固段长度、最大井斜 |
| 流体密度 | 泥浆、平衡液、隔离液、领浆、尾浆密度 |
| 流变与实验 | PV、YP、`n`、`K`、失水、稠化时间、24h强度、冲洗效率、相容性 |
| 施工 | 主排量、末段排量、替浆量、碰压、候凝方式 |
| 异常与风险 | 漏失、气层/漏层敏感深度、悬挂器失败、返高偏差 |
| 质量标签 | CBL 合格率、优/中/差等级、异常段比例 |

### 6.4 统一输出建议

优先级按高到低：

1. **CBL 数值标签**：合格率、优质率、标准化质量评分。
2. **分段级质量标签**：目的层平均质量、异常段比例。
3. **定性等级标签**：优 / 中 / 差。
