## 1. 背景与问题

2D 环空顶替求解器 `AnnulusD2DGASolver`（`cemdisp/models2d/annulus_d2dga.py`）存在若干失真，
导致模拟结果不能正确反映套管居中度对顶替效率的影响：

1. **窄边窜槽看不见**：summary 只输出全井效率 η_E，没有窄四分位效率 η_N。
2. **CFL 下弥散放大约 34 倍**：自适应时间步把 dt 从 4.0s 降到约 0.118s，但弥散系数是
   "每步固定幅值"，导致单位物理时间的弥散率被放大 dt_ref/dt 约 34 倍，混浆指标 mixing
   被钉死在约 0.59。
3. **b³ 分流在高 Re 过陡**：层流分流权重正比于 b²，没有流态修正，高雷诺数下宽边被过度加速。
4. **壁面层一次性永久冻结**：旧的 `c_min` 判据一旦判定某格 cement<c_min 就永久 wall=1，
   即使后续排量增大、剪切升高也无法解冻——在某些井（hu103、hu1）上造成全域冻结、
   η_E 约等于 0 的病态结果。
5. **I3 浮力通量近乎无效**：`eta2` 用正则化混合黏度的全场均值，`delta_rho` 也是均值，
   且 `d2dga_buoyancy_flux` 用内置 `max()` 导致数组输入直接崩溃（之前从未传过数组）。
6. **偏心度 e 硬截断在 0.55**：低居中（0.22–0.42）的真实几何被截断，居中度敏感性被压平。

## 2. 六个修正机制

所有机制以独立 `__init__` 开关叠加，**默认全部关闭**，关闭时逐位复现修正前基线。
`_compute_velocity` 返回元组由 8 扩为固定 12 元组，`_compute_props` 由 7 扩为 9 元组，
统一向 M2/M3/I3 提供场数据。

### M0 — 指标与口径层（零物理扰动，纯加键）

- summary 新增：`窄四分位效率 η_N`（嵌套中文键 + 顶层 `eta_narrow`）、
  `最终失稳指数_线性`/`_对数`（去饱和）、`评价窗效率`（每个 EvaluationWindow 的
  b 加权 η_E/η_N）、`低尾指标`（居中度<0.5 段占比、窄边 cement<0.05 体积占比）。
- η_N 用 `displacement_metrics._narrow_quarter_efficiency(cement, geom)`，
  取方位最后 ny//4 行（窄边）。
- 顺手删除 `_depth_profiles` 未使用的死形参 `wall`。

### M1 — 弥散系数按 dt 归一

- 新增参数 `dispersion_axial=0.018`、`dispersion_azimuthal=0.015`、`dispersion_dt_ref=4.0`、
  `dispersion_dt_scale=1.0`。
- 泵注分支弥散调用改为 `系数 × dispersion_dt_scale × (dt_step/dt_ref)`；
  spacer/flusher 用字面量基准 0.012（不用 0.018×0.667，那会得 0.012006 破坏逐位复现）。
- 固定 dt=4、scale=1 时系数等于旧硬编码；CFL 下每物理秒弥散量锚回 dt=4 标定状态。
- 验收脚本 `scripts/dispersion_scale_sensitivity_scan.py`（scale 属于 {0,.25,.5,1}，CFL on/off）。

### M2 — 局部流态修正（新建 `cemdisp/models2d/regime_closure.py`）

纯函数模块，实现 Maleki & Frigaard 2017 式 58–66：

- `metzner_reed_re(w,rho,n,kappa,b)`：Re_p = 6ρw²/(κ·γ̇ⁿ)，γ̇=6|w|/b，密度用 kg/m³。
- `hedstrom_number(tau_y,rho,n,kappa,b)`：He。
- `friction_laminar`：层流 f=24/Re_p（塞流核在临界 Re 处 <0.1%，不引入反向修正；
  屈服对转捩的推迟由 re_crit(He) 体现）。
- `friction_dodge_metzner`：湍流 1/√f 固定点迭代（f0=0.01，相对容差 1e-4，不超过 15 次）。
- `friction_transition`：log-Re 空间线性插值（禁硬切换）。
- `drag_weight`：层流元 R=1（保持 b² 幂律指数不降），过渡/湍流元 R=clip(f_lam_cr/f_eff,0.3,1.5)。
- 在 `_compute_velocity` 的 pref→area_weight→w 块外缓存浓度/黏度/He，
  块内固定点迭代（α=0.5 欠松弛，max_iter=24，w 相对容差 1e-3），
  迭代结束返回用收敛 R 直接归一的 w（任意迭代步精确保流量 2Σw·b·dy=q_half）。
- `re_crit = 2100·(1+0.1·He)` 为临时标定钮（见第 6 节）。
- **对 8 井实测影响中性**：Bingham 泥浆 He 高（约 24–76）把 re_crit 推高到约 7000–18000，
  实际 Re 达不到，全层流 R=1，M2 不改变结果（无副作用）。它为将来高排量/低黏井预留。

### M3 — 可重启屈服门槛（核心修复）

- 新增静态方法 `_yield_gate_wall(w,b,mu_reg,tau_y,cement_ever,cement_local,f_safety,c_min_residual)`。
- 物理：每深度列以"该列流动最快元（|w| 最大且 w>0）"为参考，按平行槽流
  τw=G·b/2 外推各元壁剪；`immobile = τw_extrap ≤ f·τy`；
  OR 残泥门 `cement_ever>0 且 cement<c_min_residual`。
- 关键不变量（评审中逐步确立）：
  - **流动参考元本身永不冻结**（ref_mask 豁免）——它确实在流；否则下一步该列 has_flow=False
    导致整列冻结，进而级联全域冻结（这正是评审抓到的 Critical bug）。
  - 前锋未到列（`cement_ever=0`）不冻结（immobile/residual 都带 `cement_ever>0`）。
  - 整列无流动且水泥已到，则整列冻结（无法定义参考 G）。
  - 去掉 γ̇ 的 1e-6 人为下限：w=0 则 τw=0 即真实静止。
- 新增参数 `enable_yield_gate=False`、`yield_gate_f_safety=1.15`、`yield_gate_c_min_residual=0.01`。
- 接在 run() 泵注分支 wall 更新处（替换原 `np.where(cement_ever>0, cement<c_min, 0)`）；
  **停泵 else 分支零改动**，wall 保持泵注末值（一步滞后天然成立）。
- c_min=0.05 保留为门关时的 fallback，逐位复现旧行为。

### M4 — e 护栏

- `e_clip_max=0.55`（默认=现行），生产跑道显式设 0.90。
- `e = clip(1-standoff, 0.05, e_clip_max)`。体积校正 scale 每 run 自动重算，half_volume 守恒。
- **硬约束：M4 必须在 M3 就位后才开 0.90**，否则宽边参考元被冻结会重演全域冻结。

### I3 — 局部化

- `d2dga_flux.py:136`：`max(eta2,1e-9)` 改为 `np.maximum(eta2,1e-9)`（修数组崩溃），类型注解改 `float|ndarray`。
- 新增 `enable_local_i3=False`：开时 `eta2` 透传水泥相黏度场（`_eta2`，非均值 mu_reg），
  `delta_rho=(rho-mud_density_gcc)*1000` 局部场；关时保持旧均值语义逐位复现。
- I3 公式本体（Zhang 2022 式 4.26）不动。

## 4. 8 井生产网格重跑结果（nz=250）

corrected = M1+M3+M2+I3+M4(e=0.90)。数据 `results/全井修正前后/汇总.csv`。

| 井 | η_E 基→修 | η_N 基→修 | mixing 基→修 | wall% 基→修 |
|---|---|---|---|---|
| hu101 | 0.420 → 0.440 | 0.023 → 0.023 | 0.321 → 0.323 | 45 → 45 |
| hu102 | 0.174 → 0.474 | 0.201 → 0.184 | 0.208 → 0.325 | 53 → 24 |
| hu103 | 0.002 → 0.434 | 0.001 → 0.146 | 0.007 → 0.268 | 100 → 41 |
| hu1  | 0.000 → 0.378 | 0.000 → 0.069 | 0.000 → 0.345 | 100 → 42 |
| hu2  | 0.530 → 0.616 | 0.433 → 0.532 | 0.217 → 0.264 | 32 → 16 |
| ht1_001 | 0.482 → 0.546 | 0.372 → 0.462 | 0.251 → 0.289 | 38 → 23 |
| ht1_003 | 0.542 → 0.664 | 0.402 → 0.556 | 0.143 → 0.220 | 40 → 17 |
| ht1_004 | 0.074 → 0.142 | 0.059 → 0.067 | 0.065 → 0.227 | 83 → 61 |

**结论**：

- η_E 在全部 8 井一致提升（+0.02 到 +0.43）。
- hu103、hu1 baseline η_E 约等于 0、wall=100% 是旧 c_min 全域冻结的病态值，修正后恢复到 0.43/0.38。
- wall% 在 6/8 井大幅下降（可重启解冻生效）；η_N 在 6/8 井提升。
- mixing 普遍上升是**正确的**：baseline 多井 mixing 约等于 0 是全域冻结冻住界面的假象，M1 修复 34 倍过弥散后真实界面混合（0.2–0.35）才显现。
- hu101 改善最小：泥浆 YP 高、假设居中度均匀，旧判据恰好没造成全域死区；启用 Task 12 的实测低居中剖面（`measured_standoff='between_centralizers'`）会放大差异。

## 5. 如何启用修正

所有开关默认关。启用方式（二选一）：

**A. 构造 solver 时显式传参**（推荐用于新 runner/实验）：

```python
solver = AnnulusD2DGASolver(
    total_t=total_t, nz=250,
    dispersion_dt_scale=1.0,      # M1
    enable_yield_gate=True,       # M3
    enable_regime_split=True,     # M2
    enable_local_i3=True,         # I3
    e_clip_max=0.90,             # M4（M3 就位后才开）
    yield_gate_f_safety=1.15,
    yield_gate_c_min_residual=0.01,
)
```

**B. 用现成脚本**：`python scripts/rerun_all_wells_corrected.py`（8 井 baseline+corrected 对比）。

hu101 实测居中度：`load_hu101_tailpipe(measured_standoff='between_centralizers')` 或 `'at_centralizers'`。

## 6. 已知边界与后续工作

1. **无井下温压流变修正**：FluidSpec 无 T/P 字段，所有流变是井口常数（化验值）。
   M3 门槛的井下定量结论待数据层 Track B；目前结论标注"井口常数流变"。
2. **M2 的 re_crit(He)=2100(1+0.1·He) 是临时标定钮**，需用三重回归锚
   （Walton & Bittleston 解析解 / Z22 Table 3 / Fooladi 数据）。对当前 8 井因 He 高而无实际影响，
   但高排量/低黏井启用前必须标定。
3. **M2 friction_laminar 的塞流核用了简化**（精确 Bingham 平面槽解在临界 Re 处修正 <0.1%，
   评审确认可忽略），若将来要精确对比 Maleki 式 60-61 可在 `regime_closure.py` 内替换，接口不变。
4. **论文数字需更新**：旧 baseline 数字（尤其 hu103/hu1 约等于 0、表4/5/6、67% 居中度阈值、
   "20 秒"卖点）基于病态冻结值，不可再用；需用 `results/全井修正前后/汇总.csv` 重算。
5. **Dodge-Metzner 在 n<0.35 时迭代可能超 15 次**：8 井 n 最小 0.545（9–11 次收敛），安全；
   若将来引入 n<0.35 流体需调大 `regime_max_iter`（已默认 24）。
6. **PACKAGE_REFERENCE.md 的元组签名文档过时**（仍写 3/5 元组），纯文档，待统一更新。
7. **M1 κ 全网格扫描**（`dispersion_scale_sensitivity_scan.py`，NZ=500，1–2 小时）可在后台跑，
   用于确认 mixing 是否落到设计期望 0.2–0.35；当前 nz=250 实测 mixing 0.22–0.35 已在区间内。

## 7. 质量保证记录

- 子代理驱动执行（subagent-driven-development），每个 Task 独立实现 + 独立评审。
- 评审共抓出并修复 **6 个真问题**：
  1. M1 spacer/flusher 系数 0.667→0.012 字面量（否则基线漂移）
