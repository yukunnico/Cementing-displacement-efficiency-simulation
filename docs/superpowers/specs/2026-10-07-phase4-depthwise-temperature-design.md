## 0. 4.0 前置声明（测绘三风险的裁定，实施前锁定）

**F-1 列场返回形态（风险1 裁定）**：逐列温度经 `_phase_props` 的**列版返回形态**承载
（返回 dict 中允许 (nz,) 数组值），**不建旁路物性通道**——保住「物性唯一入口 + 构造层=逐步派生」
两条既有不变量。均匀场（列场全等）⇒ **快捷路径原样短路回标量**（annulus `:1225-1228` /
casing 同型位），关2 逐位红线。

**F-2 memo 对策（风险1 裁定）**：`(fluid,T,P,params)` memo **只服务标量路径**（T-off/构造层/均匀场）。
逐列路径**不进 memo**：
- static 档：T(z) 与 t 无关 ⇒ **run 级一次性逐列派生**（每相 (nz,) 参数数组，缓存于 run 上下文）；
- table 档：按表时间节点（200 节点）**预计算参数数组序列**或 per-column LRU（键=舍入 T 至 1e-9 的
  唯一值集，测绘项5：键上界 nz×步数≈2.5e6 不可接受，唯一 T 去重后 ≤ 333×200 表节点量级）。
HB memo（`:2034/:2060`，T 维 `:2061-2063` 追加标量 `_step_T_c`）同规则：标量 T 才进 memo，
列场走预计算数组。**memo 键爆炸 = 验收失败项**（关5 观测：memo 尺寸落盘）。

**F-3 代表标量取法（风险2 裁定，新裁定点）**：逐列化后仍需代表标量的量——λ_op、γ̇_rep、
F²（`_froude_squared_at :1552`）、b_num（`_buoyancy_number_at :1601`）、诊断/装配标量——
**一律维持现行域均口径不变**（`_representative_temperature` 域均 → 标量链不动）。
逐列只进：①`_compute_props` 场公式（μ/ρ/τy/m/η₁η₂/nκ 场，`:1400-1455` 已全 numpy 广播，
只改上游供参）②two_layer 数组化 ③solve_stream_function 的 eta1/eta2 数组接受。
**理由**：21.7°C 断裂的教训 = 取值语义差被读成物理效应；代表标量口径若随逐列化漂移，
gate/拆分四角锚（Phase 2e）与排量锚全部失去可比性。**include_yield_term 四站点同传红线不破**：
四站点仍消费同一拆分旗标，η₁/η₂（`:1926/:1930`）可为列场、F²/b（`:1552/:1601`）维持标量——
形态差异在 A2.3 观测落盘声明。
**代价（若错）**：λ_op·F² 乘积不变量在"η₁ 列场 × F² 标量"混合形态下的相消语义需在 4b 验收中
用 T6 同型测试重新钉住（列场退化标量时逐位=现状）。

**F-4 审计与表域（风险3 裁定）**：
- fluid_at 审计环（定长 10000）与 Table 场 oob 逐查询 append（测绘项14）在逐列调用下**必爆** ⇒
  逐列路径的审计改为**聚合计数**（每相每 run 一组计数器，语义=现环的汇总；环本身只在标量路径保留）；
  oob 三件套加"列批量一次计数"入口。**审计口径变化写入台账**（诊断字段，不进 summary ⇒ 关1 不破）。
- 表时轴实测 0→**11940 s**（非 12000，测绘项15）：`stop_t > 表末` 升级为**批次级前置断言**
  （4d 交付件）；库内静默 clamp（`:253-263`）维持但计数落盘；`EXPECTED_SHAPE` 硬校验 =
  扩表（4d 时程扩展）必须先改校验并登记（改动面内声明）。
- `math.max` 陷阱：`_compute_props :1453` `max(k,1e-12)` 标量 max，列化后必须 `np.maximum`
  （测绘项8 坑位，4b 改动面显式列出）。

**F-5 消费方声明**：生产 runner 全 T-off（C-14 已裁）⇒ Phase 4 的真实消费方 =
`scripts/entrypoints/` 敏感性/探针链；波及声明按脚本清单写（run_sensitivity_current_20260916 /
run_sensitivity_temperature_t2_20261001 / 探针驱动）。
