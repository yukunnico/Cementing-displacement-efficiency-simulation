## 0. 定性：这是替换，不是实现

原始诉求是"把管内段也改为环空那种类型的二维网格"。经查证后该诉求被**替换**为另一个方案，理由与替换内容必须显式记录：

1. **环空"二维"= 轴向 × 方位角，无径向维**（间隙平均）。环空第二维之所以存在，是因为偏心 `e≠0` 打破了方位对称。
2. **管内段不存在打破方位对称的机制**（圆管、轴对称流、平盘界面）⇒"管内 × 方位"是空集。
3. **管内径向唯一有物理内容的是 Taylor 弥散**（层流速度剖面剪切展宽），而它已被 `D_eff` 以闭式吸收。写成 (z,r) 真二维 = 把闭式换成离散化，不是提升保真度。
4. **管内段当前根本没有网格、没有求解器、没有时间步进**——是体积推进的解析前缘追踪。所以"改网格"实为"从零写一个新的求解层"。

**最终交付：管内仍为 1D；新增的是"管内可视化 + 混浆带 + 与环空 2D 的拼接动画"。不交付管内二维网格。**

## 4. 口径细则

**混浆带**：`frac(z,t) = 0.5·(1 + erf((t − t_arr(z)) / σ_t(z)))`，`σ_t(z) = √(2·D_eff·t_contact(z)) / U`。

**带宽判据（Q17b + Q21A）**：带宽 ≥ `max(3 个深度网格, 0.1% × 域长)`；且每帧每界面至少一格满足 `0 < share < 1`。保留并**显式化为契约**两道现成夹取：`min(σ, 0.5·t_travel)` 与 `max(σ, dt)`。现场区间 8.0–27.3 m 仅作图注参照。

**重叠归一化**：多界面各自独立生成 erf 带后，归一化到 `Σshare = 1`（不用 clip，否则曲线和 <1 看起来像流体消失）。

**硬跳变自动判据（Q16C）**：相邻深度格之间某相 share 由 ≥0.99 跌至 ≤0.01 且带宽 < 1 格 ⇒ 标记为锐界面；命中 `plug_face_zero_mixing` 者另标"胶塞面（工艺）"，其余标"数值锐化"。

**胶塞面**：保持硬跳变，是混合带口径的**显式例外**（工艺事实：替浆顶胶塞驱动尾浆）。

**管内面板**：井筒竖条，宽度 = 管内径，横向不代表物理量；**径向渲染为均匀**。浮力滑移 (d) 只以"界面到达时刻被重力修正"的轴向形式体现。

**图注强制项**：①混浆带宽度由标定参数 α=0.25 决定，非独立物理预测；②径向剖面为均匀，非求解结果；③胶塞面为工艺锐界面。
