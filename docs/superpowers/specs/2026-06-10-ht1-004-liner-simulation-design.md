# HT1-004 井尾管段固井顶替效率模拟设计

**日期**: 2026-06-10
**状态**: 已确认
**来源文档**: `参考文档/呼1-004/HT1-004井168.3+139.7mm油层尾管控压固井施工设计 (已审批).doc`

---

## 1. 概述

基于呼1-004（HT1-004）井固井施工设计文档，使用 cemdisp 现有 1D-2D 耦合顶替效率模型，模拟该井 168.3+139.7mm 双径尾管段的固井顶替效率。

**模拟模式**: 1D 套管前沿追踪 → 2D 环空顶替（严格现场模式，与 HT1-003 一致）

### 3.2 与 HT1-003 流体差异说明

HT1-004 相比 HT1-003 的主要差异：
1. HT1-004 有两段隔离液（1.95 + 1.75），HT1-003 只有一段（2.00）
2. HT1-004 水泥浆密度更低（领浆 1.93 vs 2.05，尾浆 1.90 vs 2.05）
3. HT1-004 用"先导浆"(1.75) 替代 HT1-003 的"平衡液"(1.85)
4. HT1-004 钻井液密度 1.90，HT1-003 为 1.95

## 5. 井斜与井径剖面

### 5.1 井斜剖面

从设计文档 1.4.1 节提取，30m 间隔，范围 0-7660m。
该井基本为直井，最大井斜约 1.84°（在 6470m 处），大部分井段井斜 < 1.5°。

### 5.2 井径剖面

从设计文档 1.4.2 节电测井径表提取：
- 0-4025.73m: 245.37mm（套管内）
- 4025.73-5243.21m: 245.37mm（套管内，环容不同因钻具外径变化）
- 5243.21-5578m: 245.37mm（273.1mm 套管内，168.3mm 尾管段）
- 5578-7660m: 裸眼段，井径 242-270mm，电测分段数据

**处理方式**: 裸眼段使用文档电测数据按面积守恒换算为 139.7mm 基准等效井径。

### 5.3 居中度剖面

- 平均居中度: **83%**（来源：文档 6.3 节居中度模拟图）
- 固定值剖面（与 HT1-003 处理方式一致）: 全井段 0.83

## 7. 实现计划

### 7.1 新建文件

1. **`cemdisp/data/loaders/ht1_004_loader.py`**
   - 包含以上所有静态数据
   - 函数签名: `load_ht1_004_tailpipe() -> tuple[WellSpec, tuple[FluidSpec, ...], PumpingSchedule, ValidationData]`
   - 参照 `ht1_003_loader.py` 的结构

2. **`cemdisp/runners/ht1_004_tailpipe.py`**
   - 函数: `run_ht1_004_tailpipe_initial()`
   - 参照 `ht1_003_tailpipe.py` 的结构
   - 输出目录: `results/呼1-004_1D2D耦合模型/`

### 7.2 不修改的现有文件

- `cemdisp/models2d/` — 模型核心不变
- `cemdisp/transport1d/` — 1D 追踪不变
- `cemdisp/reporting/` — 报告导出不变

### 7.3 验证标准

- loader 可通过 Python import 无错误
- runner 可成功运行并生成完整输出文件
- 顶替效率结果在合理范围内（参照邻井 HT1-003 约 85-95%）
