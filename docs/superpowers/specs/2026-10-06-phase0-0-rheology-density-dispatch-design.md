## 2. 口径规则（定稿）

**规则 1（锚点与"就近"域）**——各族锚点与捕获区：

| 族 | 锚点（g/cm³） | 捕获区 | 宽容带宽度 |
|---|---|---|---|
| 隔离液 | 1.95 / 2.05 | **[1.90, 2.10]** | 半档间距 = 0.05 |
| 水泥 | 组B 1.90 / 组A 2.10 | **[1.88, 2.12]**（= 现状替换域，不外扩） | 现状 ±0.02（不扩） |

捕获区内一律**整式取用最近锚点公式**（6 系数二次曲面 / 组 A 或组 B 公式**整体替换**），
**不再做任何系数密度插值**。宽容带 = 区间外再加**半个锚点间距**，带内仍算「近」。

**规则 2（水泥域不外扩的理由）**：水泥现值替换域 `[1.88, 2.12]` 之外返回 `None`（不替换）。
按"半档宽容带"机械外扩到 `[1.80, 2.20]` 会把**「不替换」变成「替换」**——这是语义放大，
不是"就近取"要解决的问题；且八井水泥密度**全部落在 [1.90, 2.10]**，外扩对任何真实算例零影响。
故**不外扩**，并把"是否外扩水泥域"登记为待裁项（见 §6）。

**规则 3（平局）**：d 恰在捕获区中点（隔离液 2.000、水泥 2.000）⇒ **取高密度端**
（隔离液 → 2.05 式；水泥 → 组 A）。故捕获区取**左闭右开**：`[lo, mid)` → 低端，`[mid, hi]` → 高端。

**规则 4（远）**：捕获区外 ⇒ **维持现状**（隔离液：就近借用端点式的**整式** + `borrow` 审计；
水泥：`no_replace`），并**全部落台账待裁**（"离得太远的再考虑插值" = 处置延后，非本次实现）。

**规则 5（审计）**：新增 `nearest` 审计事件——密度**不精确等于锚点但落捕获区**时记一条
（`kind="nearest"`，含 requested 密度与选定锚点）。精确命中锚点不记（避免每步刷屏）。
`borrow`（远）语义不变。

**规则 6（T 域）**：每个锚点用**自己的**温区 —— 组 A [20,170]°C、组 B [20,200]°C。
现状"插值支"统一 clamp [20,170]（交集）随之取消。对任何真实算例无影响（三重点井 T≤150°C）。

## 4. 验收

- **关2（默认参自洽）**：`enable_temperature_rheology=False`（默认）路径**逐位不变**——
  本改动只落在 `fluid_at` 内部，T-off 根本不调用 ⇒ 结构化保证。以关1 锚 T-off 逐位复核。
- **锚点表逐位**：隔离液 1.95/2.05、水泥 1.90/2.10 四处锚点值**逐位不变**（捕获区端点=公式本身）。
- **分派对照**：八井全相 `fluid_at` 新旧对照表（`results/温变分派口径_就近取_20261006/`），
  逐相标 old→new 与差值；这是本改动**唯一**的数值影响面。
- **契约测试**：改写后的 3 用例绿；全量 `pytest tests/ -q` 失败数 **≤ 17**（不得新增）。
