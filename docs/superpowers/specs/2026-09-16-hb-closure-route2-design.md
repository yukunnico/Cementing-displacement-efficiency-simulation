## 0. 目标与非目标

**目标**：让 2D 环空**默认路径**（流函数椭圆方程 `∇a·[S+b]=0`）的速度场**真正承载非牛顿流变**——剪切变稀的剖面形状与屈服应力塞流——使模型与现场 8 井的 HB/幂律流体（水泥浆 7/8 幂律、2 口标 HB）在**流变口径上自洽**。

- 不改井斜口径、半环空设定、评价窗定义、e 口径（均属源模型边界声明范畴，另案）。

## 1. 机理论证：偏心响应为何不被破坏（研究结论）

### 1.1 偏心响应住在椭圆结构里，不在闭包里

当前新路径修好偏心响应（基准 e=0.8→0.1 跨度由 1.3pp → **75.31pp**），靠的是 (2.16) 的**全局椭圆结构**：H(φ,ξ) 经 `S = r_a∇aΨ/(2H³Ī₁)`（B&F25 (2.17)）进入算子 ⇒ 宽边通量大 ⇒ 前缘快 ⇒ 窜流。

- **路线 1（回退旧路径）失真**：因为没有椭圆方程，用代数流动度 `(b/b̄)^{1+1/n}/η_mix` + 连续性硬凑 v（`annulus_d2dga.py:1536-1544`）⇒ 基准 1.3pp。
- **路线 2 保留椭圆方程** ⇒ **不继承**路线 1 的失真。

### 1.2 HB 会改变偏心响应幅值——方向是"更强"，且这是正确的物理

| 机制 | 牛顿 | 非牛顿 | 效应 |
|---|---|---|---|
| 剪切变稀 | `w̄ ∝ H²` | `w̄ ∝ H^{1+1/n}`（幂律槽流；Walton & Bittleston 1991） | 现场 n≈0.6–0.9 ⇒ 间隙指数 3.25–3.67 > 3 ⇒ **宽窄边分流更陡** |
| 屈服应力 | 无塞流 | B&F25 (2.31)：`\|τ\|≤τ_Y ⇒ du/dy=0` | 窄边 `\|G\|H` 小，一旦 `< τ_Y` 窄边整块静止（**static wall layer**）⇒ 偏心响应更强 |
| 剖面形态 | 抛物 | B&F25 图 6：`n→0.2` 剖面趋于 plug-like、q₀ 逼近直线 | 塞流使界面更钝 |

### 1.3 必须警惕的既有过响应（与流变无关，但会被叠加）

当前牛顿基准**已过响应**（75.31pp vs 论文 31pp），归因于 **q₀ 尾缘驻滞**（`docs/源模型口径与适用域声明.md` §2.4 遗留课题 R34-1），**非流变所致**。HB 化只会在此之上**叠加更强偏心**，不会缓解。

### 1.4 ⇒ 硬设计约束（内建验收锚）

> **HB 闭包必须在极限 `n₁=n₂=1`、`τ_Y,1=τ_Y,2=0` 时逐位退化为现有牛顿闭包**；基准算例 e=0.8→0.1 跨度的 75.31pp 必须原样复现。

这给出一个内建回归护栏：HB 实现不可能"悄悄改坏"已做对的牛顿偏心响应。

### 1.5 技术事实：椭圆方程对非牛顿天然非线性（决定阶段 B 边界）

由 (2.14)：`Ī₁ = (1/H³)∫ỹ²/η(τ) dỹ`，HB 的 `η=η(τ)`（(2.34)）依赖剪切 ⇒ 依赖 `G`。单流体幂律标度给出 `Ī₁ ∝ (HG)^{(1−n)/n}`。

⇒ **即便 τ_Y=0 的纯幂律，闭包也依赖 G，椭圆方程非线性**。"把 `(b/b̄)^{1+1/n}` 塞进新路径"**不可行**（那只是代数流动度，无 G 依赖、无椭圆结构）。这正是 B&F25 需要附录 A 的 Uzawa 迭代的原因。**阶段 B 的正确定位 = 框架 + 屈服门接入 + 幂律一阶线性化 + 牛顿极限护栏**，非"换指数"。

## 3. 两阶段分解

### 阶段 B（~1 周）：框架 + 屈服门接入 + 幂律一阶 + 回归护栏

**B-1 闭包接口抽象（管线化，零行为变更）**
- 新增 `models2d/hb_closure.py`：定义闭包协议 `ClosureProvider`，暴露 `mobility(c̄, m, eta1, eta2, H, **params) -> I1` 与 `buoyant_mobility(...) -> I2`。
- 现有牛顿闭包 `two_layer.mobility_i1/i2` 包成 `NewtonianClosure`（逐位等价）。
- `stream_function.solve_stream_function` 增加 `closure=NewtonianClosure()` 形参（默认牛顿 ⇒ 逐位不变）。
- **验收**：全量测试逐位通过，基准 10 算例 η_E/t_br 与 HEAD 逐位一致。

**B-2 屈服门接入椭圆算子（真物理增益）**
- 冻结区 mobility→0 的**椭圆兼容**实现：`I₁_eff = I₁·max(1−wall, 1e-6)`，cell 系数取 `a_cell = 1/(2I₁_eff)`（`c_cell = r_a/(2I₁_eff)`）。
  - ⚠️ **方向警示（2026-09-16 Task 2 实测订正）**：**不是**把 `(1−wall)` 乘到 `a_cell` 上。`a_cell = 1/(2I₁)` 是**导度**，冻结须**放大**它（∵ 冻结 ⇒ I₁→0 ⇒ a_cell→∞ ⇒ 该区 Ψ 趋于平直 ⇒ w→0）。初版规格误写为 `a_cell=1/(2I₁)·(1−wall)`，实测冻结区速度反而升到基线 2.4–3.2 倍、窄边份额上升（一维解析同理：`a` 越小，`Ψ'=J/a` 越大）。计划自带的验收测试 `mean|w1|<mean|w0|` 正是正确物理，挡下了这一错误。
- `annulus_d2dga._velocity_stream_function` 消费 `wall`（当前丢弃）。
- 默认 `enable_yield_gate` 保持 True；提供 `enable_yield_gate_in_stream=False` 回退（逐位退回 HEAD）。
- **验收**：`wall` 全零时逐位=HEAD；`wall>0` 时窄边速度与 η_N 下降、且守恒仍成立。

**B-3 幂律一阶线性化（近似，明确标注）**
- **指数推导（B&F25 (2.14) + 幂律槽流）**：单流体幂律 `ū ∝ H^{1+1/n}G^{1/n}` ⇒ `I₁ = Hū/G ∝ H^{2+1/n}G^{1/n−1}`；相对牛顿 `H³` 的**场修正因子 = `(H/H̄)^{1/n−1}`**（n=1 时恰为 1，退化为牛顿）。
- **G 依赖可消**：椭圆解按 Q 归一（BC Ψ(0)=0/Ψ(1)=1），`G^{1/n−1}` 为纯标量因子 ⇒ 在 flux 归一化中消去；**唯一进入算子形状的是 H 依赖**。故一阶近似 = 把 `I₁` 乘上 `(H/H̄)^{1/n−1}`（在上一步 G 代表值处线性化）。
- 严格仅在 `n<1` 时生效，`n=1` 逐位退回。
- **标注**：`docs/源模型口径与适用域声明.md` 增补声明——此为一阶近似，**不是** B&F25 闭包口径，不得引 B&F25 声称方法学。
- **验收**：n=1 逐位=HEAD；n=0.7（因子 `(H/H̄)^{+0.43}`，注意指数为**正**）时宽/窄流动度比增大 ⇒ 偏心更陡。
  - 依据：**单流体幂律槽流积分** `I₁ ∝ H^{2+1/n}`（Task 3 评审独立数值核验：n=1/0.7/0.4 → H 指数 3.000000/3.428571/4.500000，与解析 `2+1/n` 6 位小数全等）。
  - ⚠️ **不得写"与 B&F25 图 6 一致"**（2026-09-16 评审订正）：图 6 是**固定几何下的 c̄ 扫描**（Ī₁(c̄) 水平线抬升、q₀(c̄) 与间隙内 `w(y)` 剖面变钝），**不含几何/方位反差轴**——该论据是松引用，改用槽流积分。

**B-4 牛顿极限回归护栏 + 中间态量化**
- 新增契约测试 `tests/contract/test_hb_newtonian_limit.py`：断言 B-1~B-3 在 n=1,τ_Y=0 时与 HEAD 逐位一致。
- 跑**八井 A/B**（`enable_stream_function` on/off × 流变口径），产出"流变对 8 井 η 净影响"的**首个可复核数字**（填补 R34 缺口）。
- **产出**：`results/流变口径A-B_2026-09-16/`（对照表 + 口径说明）。

### 阶段 A（3–4 周）：完整 B&F25 闭包

**A-1 一维间隙 HB 求解器**（新建 `models2d/gap_solver.py`）
- 按 B&F25 附录 A：(A12) 凸极小化 → (A15) 增广拉格朗日 → Uzawa (A18/A20/A21)。
- 交错网格（`ũ` 在格边、`λ,q,c̄` 在格心，A.2.3）；q 用二分（A20/A29）；`ρ=r=1`（满足 A31）；收敛判据 `‖·‖_p`，`p=1+min(n₁,n₂)`。
- 两种模式：固定 G（A.2.1）、**固定 ⟨u⟩=∇aΨ 反求 G**（A.2.2，D2DGA 实际需要）。
- **验收**：复现 B&F25 图 6（Ī₁/q₀ vs c̄ 随 n 变化）与图 18/19（收敛）。

**A-2 HB 无量纲群 + 闭包查表**
- 实现 (2.29)–(2.34)：`μ̂e`、`τ̂₀`、`m=κ̂₁γ̇₀^{n₁−n₂}/κ̂₂`、`B=max{τ̂_Y}/(μ̂eγ̇₀)`、`κ_k=m^{∓0.5}/(1+B)`、`τ_Y,k`。
- 预计算 `Ī₁/Ī₂/q₀/Ī₃(c̄; n₁,n₂,κ₁,κ₂,τ_Y,1,τ_Y,2)` 高维表 + 运行时插值（替代 `two_layer` 牛顿闭式）。**I₃ 仍用 Z&F22 (4.26)**（硬约束；B&F25 (2.27) 印刷式不自洽）。
- **验收**：n→1,τ_Y→0 时查表退回牛顿闭式（B-4 护栏复用）。

**A-3 椭圆方程非线性外迭代 + 接线**
- `stream_function` 增加固定点外迭代：冻结 `Ī₁` → 解 Ψ → 用 A-2.2 反求局部 G → 更新 `Ī₁` → 收敛。
- 接线进 `_velocity_stream_function`，替换标量表观黏度口径（η₁/η₂/m 改由 HB 群驱动）。
- **验收**：① 牛顿极限逐位=HEAD；② 基准 10 算例三门槛重跑（目标不劣于现 1/3）；③ 八井 HB 口径重跑 + CBL 窗口对照。

```
├── hb_closure.py      【新，B-1】闭包协议 + NewtonianClosure + HBClosure（A-2 填充）

```

**接口契约（B-1 冻结，A 不得改）**：
```python
class ClosureProvider(Protocol):
    def mobility(self, c_bar, eta1, eta2, H, *, wall=None) -> Array: ...      # → I₁
    def buoyant_mobility(self, c_bar, eta1, eta2, H, *, wall=None) -> Array: ...  # → I₂
```
- 牛顿实现：`I₁ = H³·n₁(c̄,m)/√(η₁η₂)`（逐位=现 `mobility_i1`）。
- HB 实现（A）：由 (2.14) 数值积分 + 查表给出，**额外依赖 G**（G 由外迭代提供）。
