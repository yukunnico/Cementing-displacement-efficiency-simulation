**接口契约（阶段 B 已冻结，A 不得改）**：
```python
class ClosureProvider(Protocol):
    def mobility(self, c_bar, m: float, eta1: float, eta2: float, H) -> Array: ...
    def buoyant_mobility(self, c_bar, m: float, eta1: float, eta2: float, H) -> Array: ...
```

**A 的扩展方式**：`HBClosure` 额外持有 `(n₁,n₂,κ₁,κ₂,τ_Y,1,τ_Y,2,B,m)` 与**当前 G 场**；`mobility()` 返回查表/现算的 `Ī₁`。G 由外迭代通过 `set_pressure_gradient(G)`（或构造参数）注入——**不破坏 Protocol 签名**。

## 3. 三步分解与验收

### A-1 一维间隙 HB 求解器（新建 `models2d/gap_solver.py`）

**职责**：给定 `(c̄, n₁,n₂, κ₁,κ₂, τ_Y,1,τ_Y,2, G, Gb)` → 返回 `(ũ(ỹ), Ī₁, Ī₂, q₀)`（或反向：给定均速求 G）。

- 按 A.2.3 交错网格离散；`ρ=r=1`；`q` 用二分（A20/A29）；
- 两种模式：`solve_fixed_G(...)`、`solve_fixed_mean_velocity(...)`（A.2.2，D2DGA 用）；
- 收敛判据 `‖·‖_p`，`p=1+min(n₁,n₂)`；超时/不收敛**抛错**（不静默回退）。

**验收（L2 文献复现）**：
- 复现 **B&F25 图 6**：`Ī₁(c̄)` 与 `q₀(c̄)` 随 `n=1/0.8/0.6/0.4/0.2` 的形态（m=1、w̄=1、b=0）；
- 复现 **图 18/19** 的 Uzawa 收敛行为；
- **解析极限用例先行（TDD）**：① 牛顿 n=1,τ_Y=0 → 与 `two_layer.mobility_i1/i2` 逐位一致；② Bingham n=1,τ_Y>0 → 与已知 Bingham 槽流解一致；③ 单流体幂律 → `I₁ ∝ H^{2+1/n}` 斜率（阶段 B 已数值核验 6 位小数）。

### A-2 HB 群换算 + 闭包查表

- 实现 (2.29)—(2.34) 的 `μ̂e / τ̂₀ / m / B / κ_k / τ_{Y,k}`；
- 预计算表 `Ī₁/Ī₂/q₀(c̄; n₁,n₂,κ₁,κ₂,τ_Y,1,τ_Y,2)` + 运行时插值；
- **按 8 井实际参数范围裁剪维度**（先 2 维 `(c̄, B)`；n/κ 用实际值），避免 6+ 维表爆炸。

**验收**：`n→1, τ_Y→0` 时查表**退回牛顿闭式**（复用阶段 B 的 L1 护栏）。

### A-3 椭圆方程非线性外迭代 + 接线

- `stream_function` 增固定点外迭代：**冻结 `Ī₁` → 解 Ψ（线性 Poisson）→ 由 ∇aΨ 反求局部 G（A-1 定均速模式）→ 更新 `Ī₁` → 收敛**；欠松弛；
- `annulus_d2dga._velocity_stream_function` 在 `enable_hb_closure=True` 下改用 `HBClosure` + 外迭代；
- **不收敛 ⇒ 回退牛顿闭包并告警**（不得静默）。

**验收**：① 牛顿极限逐位 = HEAD；② Z&F22 Table 3 十算例三门槛**不劣于现 1/3**；③ 八井 HB 口径重跑 + CBL 窗对照（记录，不作主验证）。

## 5. 前置判断与风险

> 依据：`docs/superpowers/research/2026-09-16-yield-gate-inertia.md`（2026-09-16 八井逐井实测）。

### 5.1 屈服项不会惰性；但**不得**用阶段 B 的 V1 Δη 预测 A 的收益

**调查结论（三条，直接引用）**：

1. **B&F25 的屈服项不会同样惰性**：实测全泥段 `B = τy/τw = 0.36–0.68`（**O(1)**，不是 10~100）；Bingham 槽流因子 `Q/Q_N = 1 − 1.5B + 0.5B³ = 0.15–0.49` ⇒ **30–85% 流动度削减**，是首阶效应。
2. ⚠️ **但"当前屈服门"与"HB 屈服项"是两个不同的数学对象，不可互相外推**：现门是阈值函数 `wall = clip(1 − τw_extrap/(f·τy), 0, 1)`（`τw ≥ 1.15τy` 时削减**恰为 0**）；HB 闭包是 `η_k = η_k(τ)` 的**平滑衰减**。**V1 的 Δη（hu101 −2.1pp、其余≈0）不能外推成 A 的预期收益。**
3. **须同时记录一条独立口径缺陷**：`τy` 场由相体积加权、**幂律相贡献 0**（`annulus_d2dga.py:706-711, 857-864`）⇒ 现门冻结的是**残泥**，且**水泥充满处 τy≡0 ⇒ wall≡0**。7/8 井水泥为幂律，故末期 `τy_med = 0`。

**⇒ 对 A 的验收设计有一条硬性要求**：

> **A 的 A/B 中"换 Ī₁ 闭包"与"补水泥 τy"两个变化会同时出现**（HB 闭包自然给水泥真实 τy）。**必须在 A 的验收里分开报告**：
> (a) **只换闭包**（保留旧 τy 口径）——隔离"剪切变稀/间隙剖面"的贡献；
> (b) **只补水泥 τy**（保留牛顿闭包）——隔离"屈服"的贡献；
> (c) 两者同时（生产口径）。
> 否则归因不清。

**附：几何是硬约束**。触发条件 `G ≡ (b_i/b_ref)·(τw_ref/τy_i) < f = 1.15`，其中 `b_i/b_ref = SO/(2−SO)`：hu101（SO 0.430）→ 0.235（7.8× 余量，唯一窄边冻结）；ht1_003/004（SO 0.830）→ 0.709（≈1.0，几何锁死）。**SO ≥ 0.80 的井即使把 `f_safety` 抬到 3.0 也几乎不动**（ht1_001 ±0.04pp）——这属几何，不是参数问题。

### 5.2 路径口径仍未裁定

阶段 B A/B 结论：V4（流函数 vs 旧代数路径）效应 **Δη_E ∈ [−71.04, +7.83] pp 且符号随井翻转**，比流变口径大 1–2 个数量级。**A 的收益必须在"路径口径已定"的前提下才可读**——否则流变效应被路径误差淹没。

### 5.3 其余风险

- **B&F25 无外部验证**：交付后论文只能写"扩展应用，未获外部验证"。
- **Uzawa 收敛性**：固定 `ρ=r=1`（A31 已满足）；二分内层；外层固定点 + 欠松弛；**超时回退牛顿并告警**。
- **查表维度过高**：按 8 井参数裁剪；先 2 维 `(c̄, B)`。
- **转录/公式误读**：所有公式**先写进 `tests/contract/test_gap_solver.py` 的解析极限用例**再实现（阶段 B 的 C1 教训：护栏测试救了错误规格）。
