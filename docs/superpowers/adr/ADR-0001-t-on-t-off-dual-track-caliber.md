# ADR-0001：T-on / T-off 双轨敏感性口径

- **状态**：已接受（2026-10-06）
- **决策者**：用户（Q2 裁定 2026-10-05；执行窗口 2026-10-06 落地）
- **落地阶段**：Phase 1（R1 温变流变公式系数参数化 + P-1 静压接入）
- **相关文档**：`docs/superpowers/specs/2026-10-06-phase1-fluid-at-signature-wave-design.md`；
  上游《温压耦合真响应改进方案_2026-10-05》§2 R1；评审A《R1–R4 设计对抗评审》§1 D-04/D-09

---

## 背景

模型有两套流变参数来源：

1. **loader 静态参数**（现场六速反解 / 设计给出的 `plastic_viscosity_pa_s`、`yield_stress_pa`、
   `power_law_n`、`consistency_k`）——即 T-off 路径消费的东西；
2. **温变流变公式**（`cemdisp.data.rheology_vs_temperature.fluid_at`）——组 A/组 B 水泥、
   隔离液六系数含压二次曲面、钻井液实测拟合；即 T-on 路径消费的东西。

两者并存时，一个自然但**错误的**做法是"相对缩放"：拿公式值与 loader 值求比值再调节。
更危险的是**把两套当同一杆杠杆**：例如把"水泥 `power_law_n` +0.1"这类 T-off 输入杠杆
搬到 T-on 语境下解读——T-on 已把水泥相的模型族切到 Bingham（`power_law_n`/`consistency_k`
被清空），该杠杆在 T-on 下**结构上不存在**。

## 决策

**采用 T-on / T-off 双轨口径；T-on 一律"绝对替换"，且不恢复经典 n/K/PV 输入杠杆。**

具体：

1. **绝对替换**：凡有温变公式的相，T-on 时以公式值**整体替换**该相流变参数
   （τy→`yield_stress_pa`、μp→Bingham 塑性粘度、模型族切 `RheologyModel.BINGHAM`、
   幂律参数清空）；**不做**相对缩放、不做部分替换、保留密度/名字/角色。
   （用户裁定 D4 = **B**；实现见 `rheology_vs_temperature._derive`。）
2. **双轨呈现**：一切敏感性产物（汇总表 / 分解表 / 口径差对照表）按 **T-off 轨**与
   **T-on 轨**分别列出，不混谈、不合并成"温度影响"一个数。
3. **口径差与温度场效应分离**（CONTEXT.md 已入册）：
   - **口径差** = （60 °C 常数档 − T-off）——公式口径替换 loader 口径本身的系统差；
   - **温度场效应** = （瞬态/静温档 − 60 °C 常数档）——温度场随时间/工况变化的净效应。

   T-on 数字**必附**该分解（计划 §7 红线）。
4. **L4 明确不属于验收**：经典 n/K/PV 杠杆在温变开启下的"复活"（L4）**不是**本模型的能力，
   也不列为验收项（`CONTEXT.md`「流变响应验收（L1–L3）」节）。
   验收三层：**L1** τy 进流场（gate-on/off 位移）／**L2** 流变是敏感性轴（R1 公式系数扰动
   产生非零可解释响应）／**L3** 跨井流变差异传导（公式分派）。
   **L2 由 Phase 1a（R1）达成**。
5. **开关默认关**：`enable_temperature_rheology` 默认 `False` ⇒ 数值路径与
   HEAD **逐位一致**（关1 红线）；T-on 一切走运行侧 opt-in。`_SWITCH_DEFAULTS` 为开关默认值
   的单一真源，一字不改。

## 后果

**正面**

- 公式口径与 loader 口径的差异被**显式量化**（口径差对照表 v1 → P-1 后须重跑为 v2），
  而不是隐藏在"调参"里；审稿可复核。
- 双轨呈现使"温度到底贡献了多少"成为可回答的问题（口径差 / 温度场效应两分量）。
- 默认关 + 逐位锚使 T-on 的引入**不可能**悄悄污染既有 T-off 权威结果。

**负面 / 代价**

- 同一物理量有两套参数来源，误解风险实存（本 ADR 的存在理由）；产物必须逐条标注口径。
- 经典敏感性杠杆（`cement_n_*`、`mud_pv_*`）在 T-on 下**失效**——敏感性表在 T-on 轨必须
  换成"公式系数扰动"这条新轴（R1 参数化的存在理由；`run_opts["rheology_formula"]`）。
- T-on 轨迹的每一处改动都要付"口径差表重跑"的成本（P-1 落地即触发 v1 作废）。

**已知敞口（登记，不修复）**

- **D-09 负物性角落**：隔离液 **2.05 式**在 T ≳ 172 °C 且低压（P ≲ 85 MPa @200 °C）下
  `τy < 0`（`_quad6(sp_2p05_ty, 200, 0.1) = −3.22 Pa`）。该角落**在本次参数化之前即存在**
  （同系数同表达式），非 R1 引入；`FluidSpec` 构造校验（`yield_stress_pa ≥ 0`）会**响亮拒绝**，
  不会静默进入求解器。三重点井物理可达域（T ≤ 155 °C）内 τy ≈ 5.8–6.0 Pa，**安全**。
  契约测试 `tests/contract/test_rheology_formula_params.py::test_known_negative_corner_is_pre_existing_and_unchanged`
  显式钉住该事实。
