## ① 消费端语义（判据）

| 锚点 | 结论 |
|---|---|
| `cemdisp/data/well_spec.py:130` | `shoe_lag_volume_m3: Optional[float] = None  # 鞋口处迟到体积（m³）` |
| `cemdisp/data/well_spec.py:191-193` | `__post_init__` 只校验"正有限值"：`_require_positive("shoe_lag_volume_m3", ...)`；无上下界、无与井深的交叉校验 |
| `cemdisp/transport1d/casing_flow.py:912-940` | `_pipe_cross_section_area` docstring 原文：**"shoe_lag_volume_m3 是从地面到鞋口的管内迟到体积（m³），除以鞋口深度得到等效截面积。"**（`:919-920` 返回 `shoe_lag_volume_m3 / shoe_md_m`） |
| `cemdisp/transport1d/casing_flow.py:895-910` | `_timeline_pipe_volume` 优先级：`shoe_lag_volume_m3`（原样返回体积） > 双径内径链 > `legacy_pipe_volume_m3` |
| `cemdisp/transport1d/casing_flow.py:258-262` | `run()`：`pipe_area_m2 = _pipe_cross_section_area(...)`；`pipe_volume_m3 = shoe_depth_m * pipe_area_m2`（= 该常量）；`arrival_pipe_volume_m3 = _timeline_pipe_volume(...)`（= 同一常量） |

**语义判定（代码口径）**：字段被消费为一个**体积**，其含义被显式写为"**地面→鞋口的管内迟到体积**"，
并被用作两条等价链：①前沿/尾缘到达鞋口的"体积坐标偏移量"；②"等效截面积 = 体积 ÷ 鞋深"。

**到达判据（决定是否触发回退）**：

| 锚点 | 公式 |
|---|---|
| `casing_flow.py:1026-1040` `_front_arrival_time` | `target = 该步 cumulative_volume_start + pipe_volume`；`target > 末步 cumulative_volume_end + 1e-12` → **`return None`** |
| `casing_flow.py:1102-1116` `_rear_arrival_time` | `target = 该步 cumulative_volume_end + pipe_volume`；同样 `None` |
| `casing_flow.py:286` / `:324` | `None` → `arrival_time_s = pumping_end_time_s`（**即用户看到的"回退为泵注结束"**） |
| `casing_flow.py:339` | 另有一道 `if rear_arrival_time_s > pumping_end_time_s: rear_arrival_time_s = pumping_end_time_s` 的钳制 |

⇒ 因此"某候选是否触发回退"的判据可纯算术化：**候选值 ≤（泵注末步累计体积 − 尾浆步累计结束体积）** 即到达；否则回退。
