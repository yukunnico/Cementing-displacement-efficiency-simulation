## 6. 与"改动程度是否合适"的关系

**该问题本轮无法回答，且答案正是这 12 个 HB run 要出的东西。**

已完成的 19 个 run 全是牛顿口径行，它们说明：
- B-2 开关（`enable_stream_yield_gate`）效应很大：hu101 η_N 0.8306 → 0.7194（**−11.1 pp**），其余井 ≤0.004 pp；
