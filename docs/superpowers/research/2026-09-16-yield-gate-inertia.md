## 1. 判据核对：我读到的门的真实语义

### 1.1 代码位置与逐行语义

`cemdisp/models2d/annulus_d2dga.py:763-822`（`_yield_gate_wall`），调用点 `:1925-1928`：

```python
# :788-800
gamma = 6.0 * np.abs(w) / b               # 6w/b：平行板缝隙平均速度→壁面剪切率
tau_w_field = mu_reg * gamma              # 该元"自身"的壁面剪应力
w_rank = np.where(w > 0.0, np.abs(w), -1.0)
ref_row = np.argmax(w_rank, axis=0)       # 每列参考元 = 该列 |w| 最大且 w>0 的元
tau_w_ref = tau_w_field[ref_row, col]     # (nz,)
b_ref     = b[ref_row, col]               # (nz,)  ← 是该元处的 b，不一定是 b_max
G         = 2.0 * tau_w_ref / b_ref       # 平行槽流 τw=Gb/2 反推压力梯度
tau_w_extrap = G[None,:] * b / 2.0        # = tau_w_ref * (b/b_ref)
# :810-813
tau_ref = f_safety * tau_y                                    # f_safety = yield_gate_f_safety = 1.15
wall_raw = np.where(tau_ref > 0.0, 1.0 - tau_w_extrap/tau_ref, 0.0)
wall_new = np.clip(wall_raw, 0.0, 1.0)
# :816-821 三重掩码
wall_new = np.where(cement_ever > 0.0, wall_new, 0.0)          # 前锋未到的元不冻结
wall_new = np.where(ref_mask, 0.0, wall_new)                   # 参考元自身恒不冻
wall_new[:, ~has_flow & any(cement_ever>0)] = 1.0              # 整列无流动且水泥已到 → 全冻
```

**你给的描述基本正确，两处需修正**：

1. `b_ref` 不是 `b_max`，而是**该列最快元处**的 b（实测 50–60/60 列落在 φ=0 即最宽处，见 §4.2 核验 2）；
2. `mu_reg` 不是"混合黏度"而是 **Papanastasiou 正则化后的表观黏度**（`:1511-1512`：`mu_reg = mu_shear + tau_y·(1−e^{−Mγ})/γ`，M=100），即 `tau_w_field` **本身就含屈服项** `τy(1−e^{−Mγ})`。这一点对 C/D 至关重要。

### 1.2 触发门的确切不等式

单元 (i,j) 满足 `wall>0`，当且仅当**同时**：

| 条件 | 出处 |
|---|---|
| ① 示踪门：`cement_ever[i,j] > 0` | `:816` |
| ② 有屈服应力：`τy[i,j] > 0`（否则 `:811` 的分母护栏把 wall 置 0） | `:810-812` |
| ③ (i,j) 不是该列参考元 | `:818` |
| ④ **`τw_ref(j) · b(i,j)/b_ref(j) < f · τy(i,j)`** | `:810-813` |

整理成"门群（gate group）"形式（本报告的核心判别量）：

> **触发条件：G(i,j) ≡ (b_i/b_ref)·(τw_ref/τy_i) < f = 1.15**
> **冻结度：wall = 1 − G/f（clip 到 [0,1]）**
> 其中 `τw_ref = μ_reg(参考元)·6|w_ref|/b_ref`，`τy = Σ_k c_k·yp_k`（POWER_LAW 相 yp≡0）。

## 4. 结论 B：根因

### 4.1 三层结构（按贡献排序）

**(L1) 口径缺陷 —— τy 场的"流体来源"是错的（决定性）**

- `_compute_props`（`:857-864`）构造 `tau_y = Σ_k c_k·_fluid_yield_stress(fluid_k)`，而 `_fluid_yield_stress`（`:706-711`）对 `yield_stress_pa is None` **返回 0**。
- 实测 8 井流体规格（loader dump）：**只有 ht1_004 的水泥是 Bingham（yp=13/14 Pa），其余 7 井的 LEAD/TAIL/INTERMEDIATE 全是 POWER_LAW（`pv=None yp=None n=K=…`）** ⇒ 这些井的 `τy` **只由泥浆（+隔离液/平衡液）贡献**，被水泥分数稀释。
- **后果 1（冻结的是泥浆不是水泥）**：在"wall 最大步"上，冻结单元的相组成中位数为

### 4.2 代码正确性核验（5 项，逐项排除"缺陷"假设）

| # | 假设的缺陷 | 核验结果 |

## 5. 结论 C：Phase A（完整 B&F25 HB 闭包）的屈服项会不会同样惰性？

### 5.1 量级估算：B = τy/τw 是 O(0.3–0.7)，不是 10~100

用**全泥段**（`n_active=0`，此时 τy 明确 = 泥浆 yp）实测的参考元壁面剪应力 `τw_ref`：

|---|---|---|---|---|---|
| hu101 | 9.2 | 13.63 | 0.675 | **0.141** | 0.325 |
| hu102 | 10.0 | 23.87 | 0.419 | **0.408** | 0.581 |
| hu103 | 10.0 | 16.60 | 0.602 | **0.206** | 0.398 |
| hu1 | 8.0 | 22.36 | 0.358 | **0.486** | 0.642 |
| hu2 | 8.5 | 23.30 | 0.365 | **0.477** | 0.635 |
| ht1_001 | 6.0 | 9.95 | 0.603 | **0.205** | 0.397 |
| ht1_003 | 泥浆幂律(0) | 16.92 | — | — | — |
| ht1_004 | 8.5 | 16.14 | 0.527 | **0.283** | 0.473 |

（`Q/Q_N = 1−1.5B+0.5B³` 已用独立数值积分复核到 4 位：B=0.3→0.5635、0.5→0.3125、0.667→0.1479，见 `.tmp_research` 复现段。）

**结论**：τw/τy 在 8 井是 **1.5–2.8 倍**（宽边，全泥段），窄边更低——**B 落在 0.36–0.68 的 O(1) 区间**，而**不是 10~100**。真实 HB 槽流在这个 B 下会把流动度砍掉 **51–86%**。⇒ **B&F25 的屈服项在本仓 8 井参数下必然是首阶效应，不会惰性。**

### 5.2 当前"门"为什么弱：函数形式不同，不是物理弱

- 当前门：`conductance = 1 − wall = Q = τw_extrap/(f·τy)`，**clip 到 ≤1**。Q>1（即 τw > 1.15 τy）⇒ **削减恰好为 0**。实测 hu101 的 wall 最大步：宽边 Q = 10.82/(1.15·2.39) = **3.9**（无削减），窄边 Q = 2.96/(1.15·5.09) = **0.51**（wall = 0.49）。即削减只发生在"Q<1"的那条窄带上、且是**线性斜坡**。
- HB 闭包：同一批单元在 B=0.36–0.68 下给 Q/Q_N = 0.15–0.49 ⇒ **30–85% 削减，且宽边也削**（B=0.42 时宽边仍有 41% 削减）。
- 另一条独立证据：**当前模型对泥浆的 Bingham 处理是"标量表观黏度"口径**（`annulus_d2dga.py:1343-1345` → `buoyancy.fluid_apparent_viscosity(mud_fluid, shear_rate)`，只把 `η₁` 当牛顿黏度标量），其隐式流动度因子是 `1−B = 0.32–0.64`，比真实槽流 `F(B)` **高估 1.3–2.3 倍**。⇒ Phase A 换成 HB 闭包本身就会改变基线速度场（与屈服门开关无关）。

### 5.3 反事实实验：给水泥加真实 τy（HB 化）后，门是否被激活？

用 `dataclasses.replace` 把 7 井的幂律水泥改成 `HERSCHEL_BULKLEY`（同 K/n，加 τy_c），跑 2×2（gate off/on × τy_c），**不改任何仓库代码**：

| 井 | τy_c=0 门净效应 Δη_E | τy_c=12 Pa | τy_c=20 Pa |
|---|---|---|---|
| hu101 | −2.098 pp | **−1.525 pp** | — |
| hu102 | +0.0025 pp | +0.0022 pp | **+0.0022 pp** |
| hu1 | −0.0001 pp | — | **+0.0001 pp**（Δη_N −0.020 pp） |
| ht1_001 | −0.0018 pp | −0.0019 pp | — |
| ht1_003 | 0（逐位） | **0（逐位）** | — |

**加 τy 并没有让门显著变活**（hu101 甚至略降）。逐井诊断（`yield_gate_cement_ty_diag`，hu102/τy_c=20）给出了原因：

```
step 3730  cem=0.944  wallmax=0.000  Qmin=1.103  ty_med=20.00  twref_med=74.87
```

⇒ **判据分子分母同时被 τy 抬高**：`G = (b/b_ref)·(A_ref+τy)/τy`（`A_ref` = 参考元的黏性剪应力，实测末期 55 Pa）。所以门对**绝对屈服应力**的敏感性是**自我抵消**的：τy 从 0 加到 20 Pa，`Q_min` 只从 1.37 降到 **1.103**（差 10% 就到门）。
**这正说明"门的惰性 ≠ 屈服物理弱"**——HB 闭包的屈服项不是这个 `((b/b_ref)(A+τy)/τy)` 形式，而是**在每个间隙上按 B 平滑削减 Ī₁**。

### 5.4 C 的判定

> **B&F25 的屈服项不会同样惰性**。理由：①实测 B = τy/τw = 0.36–0.68，属 O(1)，Bingham 槽流因子 F(B) = 0.15–0.49 ⇒ 期望 30–85% 的流动度削减，是**首阶**；②当前"门"之所以惰性，是因为它是 `clip(1−Q,0,1)` 的**阈值函数**（Q>1 时削减恰为 0），而 HB 闭包是**在全部 τw/τy∈[1,∞) 上平滑衰减**；
> ⚠️ 但**静止区的空间范围仍受几何锁定**：`b_i/b_ref < f·τy/τw_ref`（§4.1 L3）——近同心井（SO≥0.78）即便有 HB 闭包，也只会得到"整体流动度下调 + 窄边接近静止"，不会有 hu101 那样的大面积冻结。**预期 effect size：速度场层面 O(10–40%)，η 层面待 A 的 A/B 实测（建议以 hu101 与 ht1_001/ht1_003 为高/低敏感两极端做对照）。**
