### 7.1 Task 4 回填（2026-09-14 实测，`F²` 已按 Z&F22 (2.6) 接线）

**`δ₀` / `r̂ₐ*` 取值约定**（论文出处：§2.1 推导段与 (2.6)）：`r̂ₐ*` = 沿环空流道平均半径（m）；
`δ₀` = **无量纲**参考间隙比，由 **`δ₀·r̂ₐ* = d̂`** 钉定（`δ₀ = d̂/r̂ₐ*`）。该约定使
`F²·b = Δρ/ρ̂₁`（Atwood 数）恒成立。**用论文自己的 Table 1/Table 2 验证通过**：
实验室几何 `D_o=44.46 / D_i=34.92 mm` ⇒ `d̂=2.385mm`、`r̂ₐ*=19.845mm`、`δ₀=0.12018`；
按 `b=Δρĝd̂²/(μ̂₁ŵ₀)` 复算 Table 2 的 b = **−50 / 100 / 1000 / 100 / 1000**（逐例吻合），
且 `F²·b` 与 `(ρ̂₂−ρ̂₁)/ρ̂₁` 逐例**逐位相等**。
