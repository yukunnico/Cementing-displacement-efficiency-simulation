# 0708资料整理与多井数据接入实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 0708 资料按“证据化提取 → 标准字段映射 → 参考文档沉淀”的链路落地，先以呼103为样板井跑通四类提取表模板，再逐步扩展到呼102和呼探1系列。

**Architecture:** 本计划不修改 `cemdisp` 求解器或 loader，只做资料治理层。核心产物是：四类 CSV 提取模板、呼103 样板提取数据、`参考文档/` 沉淀结构、以及后续井的接入路线图。

**Tech Stack:** Markdown、CSV、pandoc（docx 提取）、主代理 PDF 直读、MiniMax 图片识别（辅助）
