# 固井顶替效率模型 — 提取表模板使用说明

## 概述

本目录包含四类数据提取表模板，用于从原始资料中提取井身结构、流体体系、施工程序、验证资料四类数据，存入标准化 CSV 文件，以便后续建模使用。

这些模板文件是**空壳模板**，后续会复制到各井目录下，由工程师逐行填写。

---

## 四类提取表适用场景

| 模板文件 | 适用场景 | 数据来源 |
|---|---|---|---|
| well_spec_template.csv | 井身结构与几何参数 | 设计书、套管程序、测井图 |
| fluid_spec_template.csv | 流体配方与性能参数 | 流体设计单、配方的单 |
| pumping_schedule_template.csv | 施工时序与泵送参数 | 施工日志、泵送程序图 |
| validation_data_template.csv | 固井质量验证资料 | 测井报告、固井质量评价 |

---

## 证据等级定义

| 等级 | 含义 | 示例 |
|---|---|---|---|
| **A** | 原始正文数据，来源明确 | 设计书正文中的井深、套管尺寸 |
| **B** | 二次汇总或推算数据 | 表格中的汇总值、间接推算 |
| **C** | 类比兜底，无直接来源 | 参考邻井数据、行业经验值 |

填写时按**最高可用证据等级**填写。例如：某字段在设计书和汇总表均有，取 A 级。

## 使用注意事项

1. **模板复制**：每次新井分析时，将模板复制到该井的工作目录，井号填入文件名和表头。

2. **证据等级优先**：同一字段有多个来源时，选用最高证据等级（A > B > C），并在备注中说明其他来源。

3. **来源文件路径**：填写来源文件时使用相对路径或完整路径均可，但应保持一致，便于后续追溯。

4. **单位一致性**：所有深度单位统一使用 **m**，密度单位统一使用 **g/cm³**，排量单位统一使用 **m³/min**。

5. **空值处理**：如某字段无数据，保持该格为空，不要填-或无，以区分未填写和明确为空。

6. **Markdown 索引表**：原始资料索引_template.md 用于记录该井所有原始资料的文件列表，方便后续核对和复现。
