# 呼101尾管固井 1D-2D耦合 + 论文D2DGA环空模型结果报告

## 1. 本版模型范围

本版按项目 `cemdisp/` 结构组织：

- `cemdisp.data`：井身、流体、施工程序数据结构；
- `cemdisp.data.loaders.hu101_loader`：呼101单井数据加载器；
- `cemdisp.transport1d`：套管段1D体积前沿追踪；
- `cemdisp.models2d.boundary_bridge`：套管鞋口出流状态转换为环空入口边界；
- `cemdisp.models2d.annulus_paper_d2dga`：环空段论文D2DGA模型；
- `cemdisp.reporting`：中文结果图表输出；
- `cemdisp.runners`：呼101计算入口。

环空段只保留论文模型所需因素：偏心窄环空、黏度比、密度差/浮力数、高Peclet数间隙尺度弥散通量、二维方位-轴向水泥浓度推进。未加入泥饼、温度、凝胶强度、湍流修正、CBL校准惩罚等项目中后续扩展影响项。

## 2. 1D-2D耦合方法

套管段采用不可压缩活塞流前沿追踪，现场泵注程序整体滞后 52 m³ 后到达鞋口。鞋口出流状态作为环空二维模型入口。模型停止时刻定义为尾浆全部越过鞋口、后续替浆刚到环空入口，此时用于评价最终水泥放置。

- 套管滞后体积：52.00 m³
- 水泥到鞋口时间：85.00 min
- 尾浆结束到鞋口时间：143.00 min
- 后续替浆到鞋口时间：143.00 min

## 5. 结果解释

本版加入了套管段1D前沿追踪，因此环空入口不再人为给定为固定尾浆，而是随地面泵注序列、52 m³套管滞后体积和分段排量自动变化。与单纯环空入口假设相比，1D-2D耦合更适合描述“水泥何时到鞋、领浆/尾浆何时进入环空、后续替浆何时到达鞋口”的实际边界。

最终结果显示宽边平均水泥体积分数明显高于窄边，说明在偏心环空中存在宽边低阻通道超前推进，窄边残余泥浆风险较大。该结论来自论文D2DGA中的间隙尺度弥散与偏心通道效应；未额外加入泥饼、温度、胶结质量或测井解释折算，因此该结果应理解为水力放置意义上的顶替效率，而不是CBL测井合格率。
