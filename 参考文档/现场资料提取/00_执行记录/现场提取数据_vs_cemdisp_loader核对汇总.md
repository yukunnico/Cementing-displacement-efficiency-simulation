## 1. 总体结论

当前现场提取数据已经明显优于旧 loader 中的部分代理值，但各井可用程度差异很大。

| 井 | 现场提取覆盖 | loader状态 | 当前建议用途 |
|---|---|---|---|
| hu101 | 很丰富，含正式CBL、泵注、流体、井径井斜、复合尾管 | loader多数关键施工/流体已对上，但几何仍等效化 | 可作为主验证候选，但需明确复合尾管/等效几何假设 |
| hu102 | 很丰富，含几何、泵注、流体、CBL总结 | loader过度简化，剖面/泵注/流体差异大 | 暂作应用井，更新loader后再进主结果 |
| hu103 | 很丰富，含复合尾管、剖面、泵注、流体、CBL | loader是139.7mm下段代理模型 | 可作为复合尾管改进重点井，旧loader结果不宜直接用于论文 |
| ht1_001 | 有现场证据但原始采集噪声大 | loader含代理几何和模型化窗口 | 需先清洗施工采集数据，再考虑验证 |
| hu2/HT1-002 | 当前无独立现场提取目录可核验 | loader内部自洽但 loader-only | 暂不作为现场验证井 |
| ht1_003 | 当前无独立现场提取目录可核验 | loader基于CSV/脚本，含假设standoff | 可作为模型应用/敏感性井，需标注假设 |
| ht1_004 | 当前无独立现场提取目录可核验 | loader偏优化参数化 | 可作为优化案例，不能写成现场实测验证 |

论文风险最大的点是：**不能把 loader 自洽当作现场资料确认，也不能把模型代理值写成现场实测值。**

- 裸眼段：`5700–7868 m`
- 168.3 mm段：`5402.885–6796.136 m`，ID `138.9 mm`

- 泵注程序：平衡液25、隔离液25、领浆47、尾浆23、压塞液2、轻泥浆26、中置液10、钻井液52、循环排混浆85等
- 流体：泥浆、平衡液、驱油隔离液、领浆、尾浆、替浆等均有现场密度/流变或实验数据
- CBL：正式解释结论 `5390–7810 m` 合格率 `62.77%`，且有分段图像识别结果

### 2.2 loader 当前值

`cemdisp/data/loaders/hu101_loader.py` 关键值：

- `HU101_TOP_MD_M = 5400.0`
- `HU101_BOTTOM_MD_M = 7868.0`

- 下段尾管 OD `139.7 mm`
- 鞋口滞后体积 `52.0 m3`
- 领浆 `47 m3`，尾浆 `23 m3`
- CBL评价窗：`5700–7810 m`
- 目标层段：`7492–7735 m`

### 2.3 已确认匹配

- 井深、鞋深、悬挂器深度基本一致；
- 领浆/尾浆体积一致；
- 泥浆密度、隔离液密度、水泥浆密度与现场提取一致；
- 领浆、尾浆幂律参数与现场提取一致；
- CBL正式合格率 `62.77%` 与 loader notes 一致；
- loader已明确说明上部168.3mm+下部139.7mm变径段采用等效几何。

### 2.4 冲突 / 不确定

1. **复合尾管几何被等效化**  
   现场为168.3mm + 139.7mm复合尾管，loader为了兼容单外径求解器，对上部段使用等效井径。

2. **liner_id_mm 是由52m3鞋口滞后体积反推**  
   loader notes 已说明其不代表真实单一尾管内径。论文中不能把这个值写成现场内径。

3. **standoff 是模型假设**  
   现场只有扶正器分段布置和坐挂失败导致居中度下降的描述，没有连续实测 standoff；loader使用 `0.38–0.48` 左右的剖面，是建模假设。

4. **CBL分段数据质量不均**  
   正式合格率可信；但大量分段来自 vision/auto_analysis，后段置信度从 high 到 low 不等，需要论文中谨慎使用。

5. **回接段资料混入风险**  
   现场提取文件中还包含193.7mm回接段资料。论文主模型若研究尾管段，应明确只用5400–7868m尾管固井段，不把回接固井异常混入主尾管模型。

### 2.5 建议动作

- hu101 可作为主验证候选井；
- 论文中必须说明复合尾管采用等效几何处理；
- CBL定量验证优先使用正式 `62.77%`，分段图像解释只作为辅助；
- standoff/居中度必须标为模型假设；
- 如后续升级模型，应支持显式复合尾管，而不是只靠等效上部井径。

## 3. hu102 / 呼102

### 3.1 结论

`hu102_loader.py` 目前只把主段几何、CBL总结和35t/74m3主泵量对上了；井径井斜、泵注阶段拆分、流体流变和目标窗定义与现场提取数据差异较大。

### 3.2 已确认匹配

- TD `7735 m` 一致；
- liner OD `139.7 mm` 一致；
- liner ID `108.1 mm` 一致；
- casing ID `219.1 mm` 一致；
- CBL窗口 `6840–7665 m` 一致；
- CBL合格率 `66.65%` 一致；
- 替浆总量 `74 m3` 与汇总口径一致；
- 尾浆 `35t≈16.67 m3` 与现场 `10+7=17 m3` 接近。

### 3.3 主要冲突

1. **井径井斜冲突最大**  
   现场孔径约 `184.85–200.58 mm`，最大井斜 `11.49°@7450m`；loader使用固定 `215.9 mm`、井斜 `0.50–2.88°`，更像占位/等效剖面。

2. **泵注程序被大幅简化**  
   现场有前置液、试隔离液、隔离液、领浆、尾浆、压塞、后置、替浆和后续循环；loader默认只有尾管水泥浆和替浆液推进两步。

3. **流变参数不匹配**  
   现场泥浆 `PV66/YP10`，loader为 `PV80/YP15`；现场领/尾浆 `n≈0.737/K≈0.947`，loader为 `n=0.722/K=0.684`，且未独立建 lead slurry。

4. **target window语义混乱**  
   现场地层目标为 `J3k 7422–7640`，油气显示层为两个窄段；loader目标窗 `7405–7480`、`7502–7540` 更像CBL质量段。

5. **居中度不确定**  
   只有设计口径，无连续实测 standoff。

### 3.4 建议动作

- 替换/校正 loader 井径井斜剖面；
- 重建完整 pumping schedule；
- 增加独立 lead slurry、spacer、前置液等 FluidSpec；
- 拆分 CBL质量窗与地层目标窗；
- 更新前不建议用当前 hu102 loader 结果作为论文主结果。

## 4. hu103 / 呼103

### 4.1 结论

hu103 现场提取数据丰富，但当前 loader 更像“139.7mm下段首版代理模型”，未完整表达复合尾管、实测剖面和实际施工。

### 4.2 已确认匹配

- 139.7mm下段起点：现场 `7330.694 m`，loader `7330.6 m`；
- 井底/鞋深：`7770 m` 一致；
- 三段水泥浆参数匹配：密度 `2.05 g/cm3`，`n=0.82/0.76/0.76`，`K=0.67/1.11/1.14`；
- CBL主验证窗 `7338–7712 m` 一致；
- CBL合格率 `12.06%` 与 loader notes 一致，但未结构化为字段。

### 4.3 主要冲突

1. **几何语义冲突**  
   现场真实悬挂器约 `5536.662–5545.972 m`，168.3mm段 `5546.022–7330.694 m`，139.7mm段 `7330.694–7768.51 m`；loader把 `7330.6 m` 当 hanger/top，更像下段起点。

2. **ID/壁厚冲突**  
   现场139.7mm段 ID `107.94 mm`，168.3mm段 ID `138.9 mm`；loader使用 `121.36 mm` 和 `150.42 mm` 代理。

3. **剖面冲突**  
   现场有实测井径/井斜分段曲线；loader使用合成曲线，未覆盖完整复合段。

4. **居中度冲突**  
   现场只有设计值 `77.8%`，loader使用 `86.5%` proxy。

5. **泵注程序冲突**  
   现场设计/实际体积与排量都不同于 loader，实际有多段 `0.6 m3/min` 降排量。

6. **非水泥浆流体冲突**  
   水泥浆参数基本对，但前置液、压塞液、替浆液等密度/角色与现场差异明显。

7. **CBL结构化不足**  
   现场还有168.3mm段 `0.04%` 和整段综合约 `6.05%`，loader仅notes记录139.7mm段 `12.06%`。

### 4.4 建议动作

- 显式支持复合尾管几何；
- 用现场 caliper/inclination 替换代理剖面；
- 泵注程序拆成设计版和实际版；
- 重建非水泥浆流体参数；
- 结构化补入 `cbl_pass_rate=0.1206`，并明确只对应139.7mm段。

## 10. 必须统一的口径

### 10.1 数据类型标签

后续所有井必须区分：

- `field_measured`：现场实测/施工记录；
- `interpreted`：测井解释、图像识别、曲线数字化；
- `model_assumption`：等效井径、固定standoff、代理流变；
- `optimized_input`：优化参数化输入；
- `loader_legacy`：历史loader遗留值。

### 10.2 验证窗口

建议分开维护：

- `cbl_eval_window`：CBL评价窗；
- `cbl_quality_segments`：CBL图像/分段质量；
- `formation_target_intervals`：地层目标窗；
- `model_focus_window`：模型关注窗。

不要再混用 target interval。

### 10.3 复合尾管几何

hu101、hu103 都是复合尾管。若求解器暂时只能单外径处理，需要在论文中明确：

- 采用等效环空面积或分段近似；
- 等效值不是现场实测尺寸；
- 该处理属于降阶模型假设。
