# 0708现场资料提取执行计划

## 0. 执行目标

本计划用于指导其他AI模型或人工助手，从现场资料中**全面提取现场尾管固井数据资料**，并整理成 `cement model` 模型计算和《石油勘探与开发》论文撰写可直接使用的标准化数据。

本计划的核心要求是：

> 只提取与现场井**尾管固井**相关的数据资料，不得把其他套管段、技术套管段、表层套管段、生产套管非尾管段等资料混入尾管固井模型输入。

## 2. 提取对象边界：只提取尾管固井资料

### 2.1 需要提取的对象

只提取以下资料：

1. 尾管固井施工设计；
2. 尾管固井施工记录；
3. 尾管水泥浆设计和实验数据；
4. 尾管固井泵注程序；
5. 尾管段井身结构；
6. 尾管柱结构；
7. 尾管鞋、悬挂器、浮箍、浮鞋、扶正器等尾管附件；
8. 尾管环空对应井径、井斜、居中度或扶正器资料；
9. 尾管固井CBL/VDL评价资料；
10. 尾管固井目标层段、裸眼段、评价段；
11. 与尾管固井质量直接相关的施工异常、漏失、碰压、返出、停泵等记录。

---

### 2.2 不得混入的资料

以下资料不得作为尾管固井模型输入，除非其明确属于尾管固井段或用于定位尾管段边界：

1. 表层套管固井资料；
2. 技术套管固井资料；
3. 生产套管非尾管段固井资料；
4. 非目标套管段水泥浆性能；
5. 非尾管段泵注程序；
6. 非尾管段CBL评价；
7. 非尾管段扶正器布置；
8. 与尾管固井无关的压裂、试油、完井、射孔资料；
9. 其他井的数据；
10. 历史模拟结果。

---

### 2.3 可作为辅助背景但不得进入模型输入的数据

部分资料可以用于论文背景说明或边界校核，但不得直接混入尾管模型输入：

| 资料 | 可用途 | 不可用途 |
|---|---|---|
| 上部套管结构 | 判断尾管悬挂器以上井筒结构 | 不得作为尾管环空模型井径 |
| 全井井斜数据 | 截取尾管段对应井斜 | 不得把全井平均井斜代替尾管段井斜 |
| 全井CBL解释 | 截取尾管固井评价段 | 不得把非尾管段合格率作为尾管段合格率 |
| 全井井径曲线 | 截取尾管段井径 | 不得把非尾管段井径用于尾管段 |
| 其他套管固井水泥浆 | 对比背景 | 不得作为尾管水泥浆参数 |

## 3. 现场资料文件类型处理要求

现场资料中可能包含文字、表格、扫描件和图片。执行AI必须全面检查。

| 文件类型 | 是否必须检查 | 重点内容 |
|---|---|---|
| PDF文本文件 | 是 | 固井设计、施工总结、CBL解释、流体性能 |
| 图片型PDF/扫描PDF | 是 | 扫描表格、测井曲线、施工记录截图 |
| Word文档 | 是 | 设计正文、施工参数、表格 |
| Word内嵌图片 | 是 | 井身结构截图、施工程序截图、测井图 |
| Excel文件 | 是 | 泵注程序、井身结构、流体实验数据 |
| 独立图片 | 是 | 曲线、表格、报告截图、测井图 |
| 压缩包 | 是 | 可能包含上述所有文件 |

执行AI不能只读取可复制文本。扫描PDF、Word内嵌图片、图片中的数据必须检查。

## 6. 图片和曲线数据专项计划

### 6.1 必查图像来源

执行AI必须检查：

1. PDF扫描页；
2. Word内嵌图片；
3. Excel内嵌图片；
4. 独立图片文件；
5. 报告截图；
6. 测井曲线图；
7. 施工曲线图。

### 6.2 图片数据提取原则

| 情况 | 处理 |
|---|---|
| 图片清晰，表格完整 | OCR后结构化提取 |
| 图片为曲线图 | 进行曲线数字化，标记interpreted |
| 图片属于非尾管段 | 不提取，记录排除原因 |
| 图片同时包含多个套管段 | 只截取尾管段信息 |
| 图片井号不明 | 进入人工复核清单 |
| 图片模糊 | 低置信度，进入人工复核 |

### 6.3 曲线数字化必须记录


## 9. 质量控制规则

### 9.1 禁止混入其他套管段数据

每一条提取数据都必须判断是否属于尾管固井。

如果不能确认属于尾管固井，应标记为：

```text
uncertain_liner_relevance
```

并列入人工复核，不得直接进入模型输入。

### 9.2 现场资料优先

若现场资料与 `cement model` loader不一致：

1. 记录现场资料值；
2. 记录loader值；
3. 标明差异；
4. 优先采用现场资料；
5. 若无法判断，列入人工复核。

### 9.3 不得用历史结果补输入

`results`中的顶替效率、图表和模拟输出不能作为现场输入数据。

### 9.4 OCR低置信度不得直接用于主验证

低置信度OCR、模糊图片、坐标轴不清曲线必须进入：

```text
00_执行记录/需人工复核清单.md
```
