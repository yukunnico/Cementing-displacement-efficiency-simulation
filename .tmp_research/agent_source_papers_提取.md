## 一、Zhang & Frigaard 2022（JFM 947, A32；doi:10.1017/jfm.2022.626）——D2DGA 原始模型【最重要】

### 1.1 坐标与假设（§2.1, §4.1）

- 窄偏心环空展开为 Hele-Shaw cell；坐标 (φ, ξ)：φ 周向 ∈(0,1)（φ=0 宽边），ξ 轴向沿井深；半间隙 H(φ,ξ)。
- 窄间隙假设：d̂/(πr̂a*) = δ/π ≪ 1；速度/浓度沿径向 gap 平均，领先阶为**剪切流**（shear flow），局部 1D 剪切流方向 = 修正压力梯度方向。
- 无量纲化：长度用半周长 πr̂a*，速度用平均泵速 ŵ0，时间用 πr̂a*/ŵ0；应力尺度 τ̂0=μ̂1ŵ0/d̂（Zhang22 取法；Maleki17/Bararpour25 取法不同，见后）。
- 无量纲参数：Re = ρ̂1ŵ0d̂/μ̂1；黏度比 **m = μ̂1/μ̂2**（被顶替/顶替液）；浮力数 b = (ρ̂2−ρ̂1)ĝd̂²/(μ̂1ŵ0)；Atwood 密度比；倾角 β；偏心度 e。

### 1.2 2DGA 基础模型（§2.1，式 2.1–2.6）

| 编号 | 内容 |
|---|---|
| (2.1) | 浓度输运 ∂t[Hra·c̄k] + ∂φ[Hra·v̄·c̄k] + ∂ξ[ra·H·w̄·c̄k] = 0, k=1..K |
| (2.2) | 不可压缩 + 流函数 ∂φΨ = 2ra·H·w̄，∂ξΨ = −2H·v̄ |
| (2.3) | ∇a·[S + b] = 0（准稳态椭圆方程） |
| (2.4) | ∇a = (1/ra·∂φ, ∂ξ) |
| (2.5a,b) | S = [ra·τw(\|∇aΨ\|)/(H\|∇aΨ\|)]·∇aΨ；b = ra(ρ−1)/Fr²·(cos β, sin πφ·sin β) |
| (2.6) | Fr = sqrt(τ̂0/(ρ̂1ĝδ0r̂a*)) |

- 屈服流体：局部极限压力梯度 ra·τY/H，超过才流动，否则 \|∇aΨ\|=0 停流（§2.1 末段）。
- 数值（§2.1 末段）：规则矩形网格 + 流函数/浓度**交错网格**；浓度时间推进用 **FCT（flux-corrected transport）显式格式**；流函数方程每步用**增广拉格朗日迭代**解非线性椭圆方程。
- (2.7)–(2.11)：3D 参照模型（OpenFOAM 有限体积）：NS + 浓度输运；混合黏度闭包 **μ̂ = μ̂1·exp[c·ln(μ̂2/μ̂1)]（指数插值）**（2.11），密度线性 (2.10)；Crank–Nicolson 二阶时间；网格 20×100×400；24 核并行。

### 1.4 分层（两层）假设与浓度方程（§4.2，式 4.9–4.13）

- 两层假设：大 Pe 数下，顶替液 2 对称分散在**通道中心层** y∈[−yi, yi]，被顶替液 1 占壁面层 [−H,−yi)∪(yi,H]；几何浓度 **c̄ = yi/H**（中心层厚度占比），密度体积平均 ρ = (1−c̄)ρ1 + c̄ρ2。
- 注意：**弥散不是扩散型 D 系数**——D2DGA 的"弥散"由分层通量闭合（式 4.25 的放大因子+浮力项）体现，无自由弥散参数 D。
- 分子扩散在层流大 Pe 下忽略（2.1 无右端扩散项）。

### 2.2 行波/润滑模型（§3.1，式 3.1–3.22）

- 近轴流假设 (3.1)-(3.3)：流线伪平行轴向；界面伪平行（\|∂ξφi\|=O(ε)）；Sk,ξ=O(ε)。
- 重标度 z=εξ, t̃=εt (3.4)-(3.5)。
- 体积界面位置 Φi(z,t̃) = ∫₀^{φi} H dφ = φi + (e/π)sin πφi（3.9），(3.11) **行波双曲方程 ∂t̃Φi + ∂z q(Φi) = 0**。

- 浮力参数 b = (ρ2−ρ1)cosβ/St* (3.19)，典型负值。

## 四、Zhang & Frigaard 2023（JFM 972, A38；doi:10.1017/jfm.2023.697）【Part 2：实验对照+分类判据】

- 2DGA vs 全 3D 对照结论（摘要+§4）：实验、D2DGA、3D 三种方法前沿形状/弥散水平/前沿速度"相当接近"；D2DGA 与 3D 模型分类重合率 >90%，与实验分类图一致。
- 流态三分类：**unsteady & dispersive / steady front & dispersive / steady front & non-dispersive**。
- 稳态前沿判据 (3.1)：**Δwf = wf(C̄=0.3) − wf(C̄=0.7) ≤ 0.1 → steady front**，否则 unsteady（承 Renteria&Frigaard 2020；浓度阈值 0.3/0.7 保守选定）。
- 效率定义 (3.7)（引自 Jung&Frigaard 2022）：ηE(t̂) = ∫₀^{ẑ1}∫_{−r̂o}^{r̂o} C̄x(ŷ,ẑ,t̂)·Ŝ(ŷ) dŷ dẑ / ∫₀^{ẑ1}∫ Ŝ dŷ dẑ（截面加权体积效率；C̄x 取环空正视图浓度）。
- 窄边效率 ηN：最窄四分位环空的效率（承 Maleki&Frigaard 2019; Jung&Frigaard 2022）；e<0.6 时 ηN 收敛到高值，e=0.8 显著下降。
- 分类图（Fig.18，90 个实验点×5 偏心度）：**b ≳ 80 → 非弥散稳态前沿**；中间窄带=稳态弥散；**b<20 → 高弥散非稳态**；Re<10 极低雷诺也助稳；偏心度不改变流态分区但决定残余层量级。
- 注意区分："steady displacement"（Pelipenko04 意义：数学行波解，全效顶替）≠ "steady front displacement"（实验/数值用的阈值定义）。

## 五、次要篇目摘要（与 1D-2D 顶替模型直接相关的公式/结论）

### 5.1 Maleki & Frigaard 2017（new_8_23 抽读；J. Eng Math 103:195-？；Zhang22 采纳的 2DGA 公式直接来源）

- (17)–(19)：gap 平均连续性+流函数定义 2ra·H·w̄=∂φΨ, 2H·v̄=−∂ξΨ（注意：与 Zhang22 (2.2) 同构）。
- (20)–(23)：领先阶剪应力沿流线 τ^t_sy+τ̄_sy = −y/H·τw；τw = H·\|修正压力梯度\|。
- (24)–(26)：∇a·[S+b]=0；**S = ra·τw(\|∇aΨ\|)/(H\|∇aΨ\|)·∇aΨ；b = ra(ρ−1)/Fr²(cosβ, sinπφ·sinβ)**——与 Zhang22 (2.3)/(2.5a,b) 完全同型（Zhang22 §2.1 明言 "We adopt the formulation of Maleki & Frigaard (2017)"）。
- (27)：应力尺度 τ̂0 = max_k{τ̂Y,k + κ̂k·γ̇0^{n_k}}，γ̇0 = 3W̄/(δ0·r̂a,0)。
- (28)–(31) 边界条件：Ψ(0,ξ,t)=0；Ψ(1,ξ,t)=2Q(t)；沿 φ 对称（半环空）；∂ΩS 上 S·n=f。
- 湍流/混合流态扩展：τw 闭式 τw(\|∇aΨ\|) 承 Metzner–Reed–Dodge。
- 垂直井 β：Zhang22 的 b 定义（2.6 Froude 数）与 Maleki17 一致；Zhang22 未减静态压力场（记法差异，见 §4.1）。

### 5.2 Moyers-González, Frigaard, Scherzer, Tsai 2007（EJAM 18:477-512；瞬态效应）

- 基础模型 (1.1)-(1.5)：∇·[Ss+fs]=0；HB 屈服门同 Pelipenko04 (2.6)-(2.8)；浓度方程 (1.4) 带**时间尺度比 1/ϵ**：ε⁻¹∂t[Hc]+∇·[H(vs c, ws c)]=0；流函数速度 (1.5)。
- 瞬态贡献：流函数方程从准稳态椭圆方程变为**含 ∂t 的三阶非线性 PDE + 停流区自由边界**；梯度流方法证明唯一性/对数据连续依赖/数据不随时间变化时指数衰减到稳态。
- 核心结论：小密度差+屈服流体，流量骤降至零时流函数（速度）**有限时间停止**（finite stopping time）。
- 应用：**流量脉动（pulsation）可破坏窄边静态泥浆通道**（§4.3，20% 脉动幅值 δp=0.2 模拟）；对界面不稳定性和流量脉动研究必要。

### 5.3 Yang 等 2021（J. Petrol. Sci. Eng. 204:108691；西南石油大学）

- 内容：CFD 三相顶替（泥浆/隔离液/冲洗液/水泥浆）水平井 e=0.4 偏心环空，垫液注入序列优化；结论：偏心水平井残留在下壁面，垫液序列影响顶替效率，优化序列提升效率。
- 与本题关系：CFD 参数化场景/垫液序列叙事参考，**非方程来源**。

### 5.4 Batôt, Talon, Peysson, Fleury, Bauer 2015（Chem. Eng. Sci.；1-s2.0-S0009250915007344-main.pdf 与 赫巴相关文献.pdf **为同一文件**，MD5 相同）

- 识别：S0009-2509 = Chemical Engineering Science；Lattice-Boltzmann TRT 格式数值 + 解析 Taylor 弥散系数（多种流变）：**HB 流体 Taylor 弥散系数随流变参数变化**，解析推导各种流变的 Taylor 弥散系数。
- 与本题关系：Taylor 型弥散机理参考（管流 Taylor 弥散 D 的解析推导路线，Maleki17 湍流 Taylor 弸散闭包的层流参照）；**不是 D2DGA 弥散的来源**（D2DGA 弥散=分层通量闭合，无 D 系数，见 Zhang22 §4.2）。

### 5.5 Izadi & Frigaard 2026（Geoenergy Sci. Eng.；挤压固井）

- 内容：微环隙（microannulus）几何+水泥浆颗粒尺寸对**挤水泥（squeeze cementing）**效果；耦合 Izadi et al. 2024 数值入侵模型+泄漏预测模型。
- 与本题关系：修井作业/井筒完整性叙事；与环空顶替主过程无关，**非方程来源**。

## 七、待核事项与勘误记录

1. **Pelipenko04 的期刊卷页码**：JFM（"Prediction of travelling-wave..." 35 页），卷号/页码未在本提取中记录（待核：JFM 505, pp.339–...）。DOI/卷页码需查证。
2. **Zhang22 (2.5a,b) 的 b 定义**：b = ra(ρ−1)/F²(cosβ, sinπφ sinβ)；F 是 Froude 数（式 2.6），与浮力数 b（参数表中 b = Δρ̂·ĝ·d̂²/(μ̂1ŵ0)）**符号复用**，对照代码时注意区分"浮力向量 b"与"浮力数 b"。
3. **Bararpour25 (2.12) b 的符号**：b = −Δρ/(ra·Fr²)，"signed so that typically b > 0 in a primary cementing flow"（重顶轻向上顶替时 b>0）；与 Zhang22 参数表的 b（浮力数）数值口径不同（待核：两者换算关系）。
4. **式 4.23 核对结论**：代码注释"Z&F22 式 4.23 同型 η_mix=1/(c̄³/η₂+(1−c̄³)/η₁)"**属实**。权重是 c̄³（Poiseuille 三次方迁移率加权），η2 配中心层 c̄³（顶替液），η1 配壁面层 (1−c̄³)（被顶替液）。
5. Maleki17 (20) 中 (ρ−1) 的写法表明 Maleki17 减去了流体1静态压力场，Zhang22 (4.5)-(4.6) 未减（作者自己注明记法差异）——b 向量形式略异但物理相同，对照时注意。
6. Zhang22 (4.26) I3 分母 2m[m c̄³+1−c̄³] vs Bararpour25 (2.27) I3 分母 12[m c̄3+1−c̄³]：分子 4mc̄+3(1−c̄) vs 4mc̄+3(1−c̄²)。**两文 I3 形式不同**（Bararpour25 因尺度选择不同；Zhang22 的 4.26 与 (4.29) U 匹配时才与 Lajeunesse (4.2) 第二项一致）——三方对照时按各自来源校，**不可混用**。待核：代码 d2dga_flux.py 的 I3 实现以哪篇为准（疑为 Bararpour25 (2.27)）。
7. **Yang2021 是二进制字符问题**：txt 含特殊字符导致 grep 判二进制，摘要已用 python 读出，内容可信。
