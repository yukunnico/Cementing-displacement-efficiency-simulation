# 呼102尾管段顶替效率模型输入字段状态报告

## 1. 报告目的

本报告用于把 **Hu102 尾管段** 顶替效率模型所需输入，按 `WellSpec / FluidSpec / PumpingSchedule / ValidationData` 四类逐项整理，并对每一项标注：

- **已找到**：Hu102 尾管段主作业本地资料已能直接支持；
- **待从0708补**：Hu102 主作业直接资料不足，但 `0708` 目录中有同井其他作业或邻井可补充的工程数据；
- **待文献fallback**：本地与 `0708` 均不足，需要参考邻井或公开文献给出暂用参数/范围。

本报告服务于后续 `hu102_loader.py`、套管内 1D 输运层和环空 2D 核心的输入准备。

---

本报告只对应 **呼102井 139.70 mm 尾管段固井**，不得与 Hu102 其他套管段或回接固井作业混用。

## 9. 对模型实现的直接建议

### 9.1 首版 loader 应采用的策略

建议 `hu102_loader.py` 首版采用以下策略：

1. **WellSpec 全量落地**；
2. **FluidSpec 允许“主值 + 证据级别 + 备注”**；
3. **PumpingSchedule 先支持“尾浆 + 替浆”两段真实主流程**；
4. 前置液 / 隔离液 / 领浆若缺确证，先作为**可选补充段**而不是强制段；
5. 把所有 fallback 字段都显式写进备注，避免将估计值伪装成测值。

### 9.2 首版求解器建议

对于 Hu102 尾管段，建议第一版建模采用：

- **环空 2D 核心：必须保留**；
- **套管内 1D 输运：建议先做纯前缘追踪**；
- **套管内混合：暂不强制，等证据表明会显著影响鞋口边界时再加**；
- **前置液 / 隔离液：若主作业直接资料仍缺，先做参数化输入 + 敏感性分析**。

## 10. 当前结论

### 已经足够支撑首版模型的部分

1. Hu102 尾管段几何范围；
2. 尾管外径与技术套管等效段；
3. 井径 / 井斜剖面；
4. 尾管主作业时间；
5. 水泥浆总量、平均密度、替浆量、排量；
6. CBL 评价井段、目标层段、合格率。

### 当前最关键的缺口

1. Hu102 尾管主作业前置液 / 隔离液程序；
2. Hu102 尾管主作业实测流变；
3. 领浆 / 尾浆是否需要分浆建模及其对应流变。

### 最稳妥的首版建模路线

> **先用 Hu102 尾管主作业直接数据，把几何和主作业框架立起来；对缺失的前置液/隔离液和流变参数，优先用 0708 的同井/邻井数据补，再用文献 fallback 做敏感性包络。**

这样可以保证模型既不混井段，也不把估计值误当成真值，同时足够支撑后续 `hu102_loader.py` 和首版 Hu102 尾管段模型实现。
