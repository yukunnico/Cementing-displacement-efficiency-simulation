# 固井顶替效率模型影响因素与数据层分析报告

## 一、模型求解流程概览

模型采用分层耦合架构，各层之间通过清晰的接口传递边界条件：

```
地面施工程序层 (PumpingSchedule)
        ↓
套管内1D输运层 (CasingFlowSolver)
        ↓
鞋口边界桥接层 (boundary_bridge)
        ↓
环空2D顶替核心层 (AnnulusD2DGASolver)
        ↓
诊断与质量解释层 (diagnostics/reporting)
```

## 二、影响最终水泥浆顶替效率的主要因素

### 2.1 流体物性参数

#### 2.1.1 密度（density_kg_m3）
- **影响机制**：密度差驱动浮力效应，直接影响轴向速度分布和横向再分布
- **关键公式**：浮力数 `b = (ρ₂-ρ₁)·g·d² / (μ₁·w₀)`
- **影响程度**：高密度差（水泥重、泥浆轻）有助于窄边推进，提高顶替效率；反之加剧宽边窜流
- **单位转换**：kg/m³ → g/cc（除以1000）用于密度对比计算

#### 2.1.2 表观粘度（apparent_viscosity）
- **影响机制**：粘度决定流动度 `b²/μ`，进而影响速度场分布
- **流变模型支持**：
  - **牛顿流体**：`μ = plastic_viscosity_pa_s`（恒定）
  - **Bingham塑性**：`μ = PV + τ_y / γ`（剪切速率相关）
  - **幂律流体**：`μ = K·γ^(n-1)`（流性指数n、稠度系数K）
  - **Herschel-Bulkley**：`μ = τ_y / γ + K·γ^(n-1)`（综合模型）
- **影响程度**：高粘度流体流动阻力大，窄边死区更明显

#### 2.1.3 屈服应力（yield_stress_pa）
- **影响机制**：抑制流动，在低剪切区形成死区
- **正则化处理**：Papanastasiou正则化 `τ_y · (1 - exp(-M·γ)) / γ`
- **影响程度**：高屈服应力导致窄边流动度趋近于零，加剧窜槽风险

### 2.2 井眼几何参数

#### 2.2.1 井径剖面（hole_diameter_profile）
- **影响机制**：决定环空间隙宽度 `b = hole - od`
- **处理方法**：通过 `_depth_points()` 转换为 `DepthValuePoint` 剖面数据
- **影响程度**：间隙越大，流速梯度越显著，窄边死区效应越明显

#### 2.2.2 井斜剖面（inclination_profile）
- **影响机制**：重力沿管轴分量 = `g · cos(θ)`，影响浮力方向
- **处理方法**：按深度加权平均得到平均井斜角
- **影响程度**：斜井中重力横向分量增大，加剧重力分异导致的窜槽

#### 2.2.3 居中度/偏心度（standoff_profile）
- **影响机制**：偏心度 `e = 1 - standoff`，决定窄边/宽边间隙不对称程度
- **计算关系**：`h = half_gap_mean · (1 + e · cos(π·φ))`
- **影响程度**：高偏心度（低居中度）导致窄边间隙极小，流动困难

### 2.3 施工参数

#### 2.3.1 排量（rate_m3_min）
- **影响机制**：决定管内流速和环空平均速度
- **单位转换**：m³/min → m³/s（除以60）
- **影响程度**：高排量提高平流速度，但也增大剪切速率和湍流风险

#### 2.3.2 注入体积（volume_m3）
- **影响机制**：决定各流体段长度和前缘到达鞋口时间
- **关键关系**：累计泵入体积 - 管内容积 = 鞋口流出体积
- **影响程度**：水泥浆体积不足会导致顶替不充分

#### 2.3.3 施工时序（PumpingSchedule）
- **影响机制**：注入顺序、排量切换、停泵/续泵事件
- **处理方法**：转换为带起止时间和累计体积的内部时间窗
- **影响程度**：停泵期间考虑凝胶强度发展和沉降效应

### 2.4 物理修正模型参数

#### 2.4.1 D2DGA通量放大因子
- **公式**：`f(c, m) = [m·c² + 1.5·(1-c²)] / [m·c³ + (1-c³)]`
- **粘度比**：`m = μ_displaced / μ_displacing`
- **效果**：低浓度时 f > 1（替浆前锋跑得快），高浓度时 f ≈ 1

#### 2.4.2 浮力效应
- **浮力数**：`b = (ρ₂-ρ₁)·g·d² / (μ₁·w₀)`
- **b > 0**：密度稳定（重顶替轻），有助于窄边推进
- **b < 0**：不稳定（轻顶替重），必须避免

#### 2.4.3 轴向弥散（Taylor-Aris）
- **公式**：`D_eff = U²·R² / (192·D_mol)`（牛顿流体）
- **效果**：将尖锐前缘转换为平滑S形过渡带

### 3.4 数据处理与单位转换规则

#### 3.4.1 长度单位
- **输入**：毫米（mm）用于井径、管径
- **转换**：除以1000得到米（m）用于计算
- **示例**：`liner_id_mm / 1000.0 → liner_id_m`

#### 3.4.2 体积单位
- **输入**：立方米（m³）
- **保持**：m³用于计算，不做转换
- **时间关联**：体积 / 排量 = 时间（分钟）

#### 3.4.3 时间单位
- **输入**：秒（s）或分钟（min）
- **转换**：m³/min → m³/s（除以60）
- **示例**：`rate_m3_min / 60.0 → rate_m3_s`

#### 3.4.4 密度单位
- **输入**：千克/立方米（kg/m³）
- **转换**：除以1000得到克/立方厘米（g/cc）用于密度对比
- **示例**：`density_kg_m3 / 1000.0 → density_gcc`

#### 3.4.5 粘度单位
- **输入**：帕斯卡·秒（Pa·s）
- **保持**：Pa·s用于计算，不做转换

#### 3.4.6 屈服应力单位
- **输入**：帕斯卡（Pa）
- **保持**：Pa用于计算，不做转换

## 四、套管段模型的建立方法

### 4.1 核心算法：体积推进法

#### 4.1.1 基本原理
流体前缘位置由累计泵入体积推动，而非仅由该流体自身注入体积决定。

#### 4.1.2 关键公式

**管内容积计算**：
```
pipe_volume_m3 = shoe_depth_m × pipe_cross_section_m2
```

**前缘到达时间**：
```
target_volume_m3 = cumulative_volume_start_m3 + pipe_volume_m3
arrival_time_s = start_time_s + volume_into_step_m3 / rate_m3_min × 60.0
```

**尾缘到达时间**：
```
target_volume_m3 = cumulative_volume_end_m3 + pipe_volume_m3
```

### 4.2 物理修正模型

#### 4.2.1 重力沉降修正（Phase 2）

**基础重力因子**：
```
gravity_factor = settling_velocity_factor × (ρ - 1000.0) / 1000.0 × gravity_scale
```

**井斜角投影修正**：
```
gravity_factor ×= cos(inclination_rad)
```

**屈服应力修正**：
```
tau_critical = Δρ × g × pipe_radius_m
yield_ratio = min(τ_y / tau_critical, 1.0)
yield_suppression = 1.0 - 0.8 × yield_ratio
gravity_factor ×= yield_suppression
```

**修正后到达时间**：
```
arrival_time_s ×= (1.0 - gravity_factor)
```

#### 4.2.2 轴向弥散（Taylor-Aris模型）

**牛顿流体**：
```
D_eff = U² × R² / (192 × D_mol)
```

**幂律流体**：
```
κ ≈ 48n + 144
D_eff = U² × R² / (κ × D_mol)
```

**有屈服应力流体**：
```
D_eff = dispersion_alpha × U × R
```

**弥散时间宽度**：
```
sigma_t = sqrt(2 × D_eff × t_travel) / U
```

#### 4.2.3 停泵沉降增强模型（Phase 3）

**凝胶强度发展**：
```
gel_factor = gelation_max_factor × (1 - exp(-t / tau_gel))
```

**屈服应力效应**：
```
yield_suppression = 0.5 × yield_ratio
total_suppression = min(gel_factor + yield_suppression, 0.99)
v_effective = v_settle × (1 - total_suppression)
```

### 4.3 鞋口时间轴构建

**时间轴事件类型**：
- `FRONT_ARRIVAL`：流体前缘到达鞋口
- `REAR_EXIT`：流体尾缘离开鞋口
- `RATE_SWITCH`：排量切换
- `SHUTDOWN`：停泵
- `RESTART`：续泵
- `END`：施工结束

**事件生成流程**：
1. 按体积追踪数学生成离散事件点
2. 施加轴向弥散处理，将阶跃切换转换为平滑过渡带
3. 生成 `ShoeTimeline` 对象供后续查询

### 4.4 鞋口出流状态查询

**基本逻辑**：
```
cumulative_at_time = 累计泵入体积
if cumulative_at_time >= pipe_volume_m3:
    delayed_volume_m3 = cumulative_at_time - pipe_volume_m3
    fluid_name = 根据delayed_volume_m3定位流体
else:
    fluid_name = 初始管内流体（钻井液）
```

**停泵特殊处理**：
- 排量低于阈值（< 1e-9 m³/s）时认为泵已停止
- 停泵期间考虑沉降效应重新计算鞋口流体

## 五、套管段模型对环空段模拟的影响因素

### 5.1 边界条件传递

#### 5.1.1 直接边界传递
```python
def pipe_exit_to_annulus_inlet(pipe_exit_state):
    return AnnulusInletState(
        time_s=pipe_exit_state.time_s,
        flow_rate_m3_s=pipe_exit_state.flow_rate_m3_s,
        stage_name=pipe_exit_state.stage_name,
        phase_fractions=pipe_exit_state.phase_fractions,
    )
```

#### 5.1.2 流体角色映射
| FluidRole | 环空相 |
|-----------|--------|
| `LEAD` / `INTERMEDIATE` / `TAIL` | cement |
| `WASH` / `SPACER` | spacer |
| `MUD` / `DISPLACEMENT` | mud |

### 5.2 关键影响因素

#### 5.2.1 鞋口出流时间延迟
- **影响**：水泥前缘到达鞋口前，环空入口看到的是被推出的钻井液
- **公式**：`arrival_volume_m3 = cumulative_volume_m3 - pipe_volume_m3`
- **后果**：延迟时间不足会导致效率偏低，需延长环空求解总时长

#### 5.2.2 前缘到达时间修正
- **重力修正**：高密度流体前缘提前到达，低密度流体滞后
- **井斜修正**：斜井中重力分量减小，修正幅度降低
- **屈服应力修正**：高屈服应力抑制沉降，减缓前缘推进

#### 5.2.3 停泵状态传递
- **套管段**：停泵期间考虑凝胶强度和沉降效应
- **环空段**：泵停后冻结浓度场，不再平流、扩散或壁面清除
- **衔接**：停泵时刻的鞋口出流状态决定环空入口的冻结状态

#### 5.2.4 轴向弥散效应
- **套管段**：将尖锐前缘转换为平滑过渡带
- **环空段**：入口边界出现多相共存（水泥+泥浆混合）
- **影响**：模拟了管内混合对环空入口条件的影响

### 5.3 1D-2D耦合接口

#### 5.3.1 耦合边界提供器
```python
def build_coupled_annulus_inlet_provider(
    casing_result, casing_solver, fluids,
    split_cement_phases=False
):
    def _provider(time_s):
        pipe_exit_state = casing_solver.pipe_exit_state_at(
            casing_result, time_s
        )
        mapped_fractions = _phase_fractions_from_state(
            pipe_exit_state, fluids
        )
        return AnnulusInletState(
            time_s=pipe_exit_state.time_s,
            flow_rate_m3_s=pipe_exit_state.flow_rate_m3_s,
            stage_name=pipe_exit_state.stage_name,
            phase_fractions=mapped_fractions,
        )
    return _provider
```

#### 5.3.2 耦合模式优势
1. **物理一致性**：鞋口出流状态直接反映地面施工程序的"迟到"效应
2. **可插拔性**：1D层可独立运行，不改变环空2D求解器接口
3. **灵活性**：支持不同的耦合策略（如简化的直接传递或完整的1D追踪）

### 5.4 环空求解终止条件

#### 5.4.1 水泥尾缘越过鞋口时间
```python
cement_end_time_s = 最后一段水泥浆尾缘越过鞋口的地面累计时间
```

#### 5.4.2 物理意义
- 与参考项目的环空终止口径一致
- 后续替浆刚到环空入口时停止二维顶替评价
- 确保水泥浆在环空内有足够的顶替时间

## 七、模型求解逻辑总结

### 7.1 套管段1D模型核心逻辑

1. **体积推进**：累计泵入体积超过管内容积后，流体从鞋口流出
2. **重力修正**：密度差导致前缘加速或减速，考虑井斜和屈服应力
3. **轴向弥散**：Taylor-Aris模型将尖锐前缘转换为平滑过渡
4. **停泵处理**：凝胶强度发展和屈服应力抑制沉降

### 7.2 环空段2D模型核心逻辑

1. **几何构建**：偏心窄环空展开，半环空网格
2. **速度场**：基于局部流动度 `b²/μ`，考虑浮力修正
3. **平流输运**：反演追踪 + 双线性插值
4. **D2DGA修正**：通量放大因子 + 浮力弥散通量
5. **体积约束**：按累计入环空体积限制场量

### 7.3 关键影响因素排序

按对最终效率的影响程度排序：

1. **井眼偏心度**（居中度）→ 窄边流动能力
2. **排量与时间** → 平流推进速度
3. **密度差** → 浮力稳定性
4. **粘度比** → D2DGA通量修正
5. **流变特性** → 表观粘度、屈服死区
6. **井斜角度** → 重力方向分量
7. **施工程序** → 注入顺序、停泵事件

### 7.4 数据层关键约束

1. **单位一致性**：所有输入必须按标准单位提供
2. **剖面完整性**：深度剖面必须覆盖整个井段
3. **流体角色正确**：每个流体必须正确指定FluidRole
4. **施工步骤连续**：排量和体积必须保持一致
5. **鞋口深度合理**：必须位于井段范围内
