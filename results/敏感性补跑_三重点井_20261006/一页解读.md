## 结论 1 · 呼101（判别井）：温变使 standoff/密度全档 η_N 下移，**最优点不移动**

| | 数值 |
|---|---|
| T-on static 下 η_N 随 standoff | −0.30→**0.2743**，−0.20→0.4508，−0.15→0.5443，−0.10→0.6325，−0.05→0.7107，+0.05→0.8277，+0.10→0.8634，+0.20→0.9178，**+0.30→0.9565** |
| 单调性 | **严格单调递增（9/9）** ⇒ 无内点最优，最优点仍在**最大居中度端** |
| T-on 相对 T-off 的位移 | **全档为负**：−1.66 ~ **−5.10** pp（η_N） |
| 位移最大的档 | ±0.05 中等偏心（−4.45 / **−5.10** pp） |
| 位移最小的档 | +0.30（−1.66 pp） |
| 隔离液密度 ±100 | T-on 下同样为负：+100 → −3.46 pp；−100 → −4.45 pp（T-off 侧分别 −2.98 / −6.18 pp） |

**对 Tang 2024「最优排量/最优居中度随温度移动」的对照结论**：在本文口径下 **未观察到最优点的
随温移动**——温变（绝对替换 + 静温剖面）把整条 η_N(standoff) 曲线**下移**，而非**平移或变形出内点峰**。
受损程度呈**中间大、两端小**的形态。该结论仅对静态静温剖面成立（呼101 无瞬态表）。

## 结论 2 · 呼1-003（首建）：standoff 单调、高端饱和；排量近平
- T-on static η_N：−0.30→0.8402 … −0.05→0.9874，+0.05→0.9983，+0.10→0.9998，**+0.20 = +0.30 = 1.0000**。
- ⚠️ **退化档**：该井 standoff 剖面恒 0.83，`shift_standoff` 用 `np.clip(v+δ,0,1)`
  ⇒ **+0.20 与 +0.30 都被 clip 成 1.0，两变体剖面完全相同**。全批 27 名义格 = **25 个互异剖面**
  （呼101 9 档全互异；呼1-004 同样一对退化）。
- **排量响应≈0**：×0.6/×1.0/×1.4 的 η_N = 0.994504 / 0.994534 / 0.994491 —— 三档差异 ~4e-5、
  **非严格单调**。该井接近同心（SO=0.83）且已近饱和，排量杠杆对 η_N 近乎失效；**如实记录，非回归**
  （计划的排量响应锚**只对呼101 定义**）。
- 屈服门活化率（b 加权）在基准档为 **0**，仅在强负偏心档抬升（−0.30 → 0.0974、−0.20 → 0.0691、
  −0.15 → 0.0529、−0.10 → 0.0358、−0.05 → 0.0187）⇒ 该井 wall 通道只在引入明显偏心后才被点燃，
  这为 Phase 2 的 gate-on 预期提供了基线。

## 结论 3 · 呼1-004（饱和井）：温变**反向抬升** η_N
- T-on static 相对 T-off **全档为正**：+0.00 ~ **+4.95** pp；−0.30 档 +4.95 pp、−0.20 档 +1.16 pp。
- 与呼101 **反号** ⇒ 温变对顶替的作用方向**依赖井况**，不可跨井外推。这是「井间分化」叙事的直接证据。

## 结论 4 · 口径变更的可归因性（跨批复现校验）
- **T-off 组 4 档全部逐位相同**（呼101 `Toff_zero`；呼1-004 `Toff_zero` / `Toff_rate_x0.8/x1.2`）。
- 呼101 的 **T-on 结果亦逐位相同**：其受影响相（复合隔离液，由「平衡液 1.850 + 驱油隔离液 2.000」
  按入库体积加权）密度落在新**宽容带**内、仍取**同一个 1.95 端点式**——审计标签由 `borrow` 变 `nearest`，
  **公式未变 ⇒ 数值未变**（旧 `{clamp:1, p_default:1, borrow:1}` → 新 `{clamp:1, p_default:1, nearest:1}`）。
- 呼1-004 的 T-on 变化量可由 **领浆 1.93 → 组 B**（τy −21.9%）解释（审计新增 `nearest:1`）。
- ⇒ **口径变更的数值影响面 = 水泥相**；呼101 隔离液档虽名义改变，但经复合后落回同一端点式。
