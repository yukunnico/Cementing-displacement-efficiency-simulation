## 3. 三个辅助函数完整解析

### 3.1 Friction_annulus_bh.m / Friction_casing_bh.m — 流变模型 = 宾汉塑性（Bingham plastic），非幂律非 HB
签名（两文件除层流乘子外**逐字相同**，casing 版头注释仍写"环空"=复制粘贴）：
```
function [Ff_a, flow_pattern_a] = Friction_annulus_bh(rho_a, V_a, A_a, mu_p_a, tau_y, D_w, D_do, QL)
function [Ff_a, flow_pattern_a] = Friction_casing_bh (rho_a, V_a, A_a, mu_p_a, tau_y, D_w, D_do, QL)
```
- 入参实际单位：rho_a kg/m³、V_a m/s、A_a m²（**函数内从未消费**）、mu_p_a **mPa·s**（函数首行 `mu_p_a = mu_p_a / 1000;` 转 Pa·s；头注释误标 Pa·s——风险 R7）、tau_y Pa、D_w/D_do m（间隙 = D_w − D_do，环空水力直径语义）、QL m³/s。
- 返回：Ff_a（名义 Pa/m）、flow_pattern_a（1 层流 / 2 紊流）。
- `global pianxin PR;` 声明但**从未使用**；脚本侧 pianxin/PR 又非 global ⇒ 纯死连接。
- 井壁切应力不动点迭代（种子 100 Pa，相对容差 1e-3，maxIter=30 强制退出）：
```
tau_w_new = 8*mu_p_a*QL / (pi*((D_w-D_do)/2)^2 * (D_w+D_do)/2) + 3/2*tau_y - 1/2*tau_y^3/tau_w_old^2;
err_tau = abs(tau_w_new - tau_w_old) / tau_w_old;
tau_w = tau_w_new;   % 未收敛也用最后一次值
```
- 判别式（逐字）：
```
int1 = tau_y / tau_w;
He = 16800 * int1 / (1 - int1)^3;                                  % 注释称 "Hedstrom 数"（经验常数）
Re_a_c = (1 - 4/3*int1 + 1/3*int1^4) / (8*int1) * He;              % 临界雷诺数
Re_a = 0.81619 * rho_a * V_a * (D_w - D_do) / mu_p_a;              % 实际雷诺数（塑性黏度口径）
```
- 层流分支（Re_a <= Re_a_c，两函数唯一差异）：
```
annulus:  Ff_a = 0.8  * (6895*mu_p_a*V_a / (216*(D_w-D_do)^2) + 5.33355*tau_y / (D_w-D_do));
casing :  Ff_a = 1.25 * (6895*mu_p_a*V_a / (216*(D_w-D_do)^2) + 5.33355*tau_y / (D_w-D_do));
```
  注释自称"圆管公式×0.75 转环空"，实际乘子 0.8 / 1.25（=1/0.8）——风险 R8。
- 紊流分支（两函数相同；注释自称"核心 Bug 修复：去除 0.75 乘数"）：
```
Ff_a = 0.158278 * rho_a^0.75 * V_a^1.75 * mu_p_a^0.25 / (D_w - D_do)^1.25;
```
- 常数谱系：6895(psi→Pa)、216、5.33355、0.158278、0.81619、16800 均为 API 现场单位经验公式折算遗留，无 SI 推导；输出经验为 Pa/m。管内调用传 `D_w=管内径, D_do=0` ⇒ 间隙=全径，用 1.25=1/0.8 把"环空系数"翻回管径口径——移植须原样保留，不得替换成标准圆管 Bingham 公式。
- 退化路径：tau_w_new≤0 → int1<0；int1→1 → `(1-int1)^3`→0 除零；迭代 30 步不收敛仍赋值。Python 复刻必须保持迭代次数/容差/退出次序（流型判定对收敛精度敏感——风险 R12）。
- 被调用方：`p_jaifang1.m:669`（annulus，t×i 主循环）与 `:1308`（casing）。全项目仅此两处。

## 5. Python 移植风险清单

- **R1（最危险）`clear;clc;` :1 清除调用方状态**：已在真实 -batch 中把 wrapper 的 `t0` 清掉、diary 报错退出（wrapper_p30:20），导致 out_*.csv 靶数据**全部缺失**（§0）。Python 封装成函数、绝不复刻 clear；且 **Phase 3.1 开工前先修 wrapper（`t0=tic` 挪到 run 之后）重跑 -batch 拿逐点 CSV 靶**，否则"对靶复现"无从验收起。
- **R2 脚本 bug：管内界面 2/3 屈服应力混合抄错（:1153）**，`proportion*tau1 + (1-proportion)*tau3`，应为 tau2/tau3（同行 rou/miu 与环空对偶处 :531 均正确）。对靶复现要求**先按 bug 原样复现**（位级一致），再单独立项评估是否修正；不得静默顺手改。
- **R3 `safety_margin = 0.003` 是装饰品**：只进 fprintf/图题，四点走廊公式(:1716-1727)完全未用。移植者"照文补码"会把走廊内缩、S21/S22 输出全变。
- **R4 魔法 1200 L（:733）**：位于 `for t=2:n_time` 体内、每轮覆盖下标 1，使 `volume_injected_casing_1_list` 全序列带 +1200 L 偏置（其余 13 路没有）。它前移了管内第一界面（井浆→先导浆）的时刻/深度，泵压早期曲线形状受它影响。必须在移植中复现并加注释，禁止当作笔误删除。
- **R5 界面哨兵码 + elseif 链序**：10000/-1 被当 ±∞/-∞ 参与 `<`/`>` 区域比较驱动属性分区；S7 泵率切换链边界比较符 `<`/`>=`/`>` 混用、先命中先赢。`np.select` 必须按原分支顺序逐项生成、禁止布尔合并；0/1 基换算时哨兵本身不是索引、保持原值。
- **R6 两套界面方向相反**：环空 tag 指界面下方段（自底累计容定位）、管内 tag 指界面所在段（自顶累计容定位）；`i<tag`/`i>tag` 语义在两侧相反（:499-558 vs :1119-1279）。移植需按分支逐一对照映射，建议写方向断言单测。
- **R7 注释单位谎言**：摩擦函数头注释 mu_p_a 写"Pa·s"实收 mPa·s（内部 /1000）；`annulus_radius_array_cm_` 名为半径实为直径；CSV 带 BOM。Python：`pd.read_csv(..., encoding='utf-8-sig')` + 8 列名白名单逐字符断言。
- **R8 注释与代码常数不符**：层流"×0.75"注释 vs 实码 0.8/1.25；紊流注释自称"去除 0.75"。以代码常数为准逐字移植，注释仅存档。
- **R9 PR 恒等于 1 的数值空转链**：E=0 ⇒ PR_Friction≡1；函数里 `global pianxin PR` 与脚本局部同名变量互不可见（死连接）。移植保留 PR_Friction 函数本体（后续放开 E 的接口位），默认路径输出 1.0，且 `Ff*PR` 乘法保留。
- **R10 时间离散化细节**：`n_time=floor(189.059)=189`（尾部 ≈41 L 丢失）、泵率按时间节点切换（非体积节点）、`time_minutes_real=(1:n)'*dt`（首步=1 min、首步累计体积已=1400 L）、`t>node14` 停泵分支不触发但必须保留代码路径。对靶 CSV 的 189 行须逐行对齐，不得改 0 起点或按体积事件驱动重采样。
- **R11 绘图-计算耦合排查结果**：-batch 全程跑通（§0），**没有量只藏在绘图调用里**——S14 界面深度换算与 max/min 注记虽是"绘图准备"，但都是独立语句，结果矩阵均在 figure 之前算完；yline(:1886 等) 内联的界压表达式与 S16/S21 数组重复但仅是显示。Python 可安全剥离 matplotlib，但建议把 S14/S25 的合并段/交点逻辑（fprintf 会消费）保留在计算层。
- **R12 摩擦迭代语义**：不动点迭代种子 100 Pa、容差 1e-3、30 步强制退出后仍取最后值赋 tau_w；无解析解、无收敛失败报警。容差方向/比较写法（`abs(err)/tau_w_old`）影响流型切换时刻 → 摩阻阶跃 → ECD 阶跃。必须复刻迭代，禁止用闭式 Bingham 解替换。
- **R13 两条独立容积链并存**：界面定位用 CSV `volume_annulus_L_`（甲方表值），体积统计用 `area_cout × length`（自算）——两链有系统性小差；管内还有 `area_cin × length ×1000` 第三链。禁止归一/互相替换，各消费点按原链取数。
- **R14 钳位与截断**：泵压 `<0→0`(:1336-1338)；对比插值前累计体积钳位到参考表首末(:1621/:1655)；`unique(...,'stable')` 取首次出现；`interp1 'linear'` ≡ `np.interp`。`pressure_casing_friction` 累计链从 i=2 起（i=1 摩阻不入链），而井口泵压式(:1333)单独补加 i=1 摩阻——两处口径不同是**原样语义**（风险 R14 与第 1 段井口边界同形），不得统一。
- **R15 依赖与残留物**：`P_bit_drop ≡ 0`（:251，钻头水眼压耗缺席）——对靶时泵压含此口径。`p_jaifang_T.m`/`HT1_004_T.m`/`T_in.xlsx`/`T_out.xlsx`/`HT1-004_pump_pressure_comparison.csv` 属温度变体或旧产物，**p_jaifang1.m 全文未引用**（已核）。地热场三行(:163-165)与 HPHT 密度修正(:560-574)整块注释——本篇真温耦合为零。
- **R16 MATLAB 1 基索引与选择语义**：`pressure_annuli(t,1)`=井口段、`(:,end)`=井底列、`find(...,1,'first')`、`min(abs(...))` 最近网格点（并列取小索引）、`idx7 恒空` ⇒ 段 7 分支保留但不生效。numpy 映射后每个索引点写单测。
