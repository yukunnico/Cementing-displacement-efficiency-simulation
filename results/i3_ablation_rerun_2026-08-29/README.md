## 结论

1. **基线口径下 I3 仍无效**：R2 vs R1 = +3.2e-10（修复前 +2e-10，同量级），全场均值口径
   （eta2/Δρ 取全场均值）的 I3 通量对 HT1-004 近垂直井几乎无贡献。
2. **I3 局部化后生效**：`enable_local_i3=True`（eta2 透传水泥相黏度场、Δρ 用局部混合密度场）
   使 R2−R1 = +0.47 pp，I3 通量开始产生实际作用，方向为正（提升顶替效率）。
3. **真浮力与局部化 I3 的组合**：li3_R3 vs li3_R2 = −0.60 pp，且窜槽/失稳指数抬升
   （0.014→0.026 / 0.0117→0.0224）——近垂直井真浮力体力（f_phi ∝ sinβ）引入的方位扰动
   改变前锋形态，与局部化 I3 叠加后净效应转负；基线口径下真浮力单独作用为正
   （base_R3 vs base_R2 = +0.57 pp）。论文表述时需注意两开关存在交互。

## 归因（基线口径 I3≈0，供论文用）

- **垂直井 f_phi→0**：HT1-004 尾管段平均井斜仅 2.27°（sinβ≈0.040），方位浮力分量
  f_phi = (r_a/F²)·sin(πφ)·sinβ ≈ 0，I3 退化为纯轴向分量；
- **轴向分量散度近零**：q_xi 沿井深近常数，∂q_xi/∂s ≈ 0，残余通量散度集中在前锋薄层；
- **弥散与指标掩盖**：间隙尺度弥散抹平薄层重排，全井段平均 eta_E 对薄层效应不敏感，
  残余 +3e-10 仅为浮点噪声量级。

## 建议

论文中 R2 消融若引用基线口径（+3e-10），必须同时给出归因（近垂直井 f_phi→0），
否则审稿人会质疑 I3 项失效；或直接采用局部化口径（+0.47 pp）作为 R2 的生产配置。
