# 口径差对照表：公式值 vs 原 loader 静态参数（呼1-004）

- 公式侧 = `cemdisp.data.rheology_vs_temperature.fluid_at`（T0-2 逐字录入公式，Task 3 实现）；loader 侧 = `ht1_004_loader._build_fluids()` 静态常量——两侧来源独立。
- 网格 = 计划 §3.7 全网格温点：水泥/隔离液族 20/60/100−(=100.0)/100+(=100.1)/120/155/170 °C；泥浆族 40/50/60/70/80 °C。
- 隔离液压力 P：**P-1 已接线** —— 本表按 `HydrostaticPressureField` 的鞋深单点 **P=141.2436 MPa**（HydrostaticPressureField 鞋深单点，ρ̄=1881.05 kg/m³（在场相密度按设计泵注体积加权））求值；表中「@P」列 = 该压力下的公式值，未标 P 的列 = v1 常压缺省 0.1 MPa 口径（**v1 已作废，仅留对照**）。
- μp 单位 Pa·s、τy 单位 Pa；Δ = 公式 − loader；Δ% = (公式−loader)/loader。
- 「不替换」行（分派表行3/行9）：T-on 对该相原样返回 loader 常数 ⇒ Δ≡0。

- **口径标签复核（Q16，2026-10-06 用户裁定）**：温变公式的**密度分派**已由「六系数/组间**插值**」改为「**就近取整式**」——隔离液捕获区 [1.90,2.10]（=锚点区间+半档宽容带，平局取高密度端 2.05）、水泥捕获区 [1.88,2.12] 不外扩（平局取组 A）；捕获区外维持「就近借用端点整式 + borrow 审计」。本表数值即**就近取口径**；引用旧版（含「插值」字样）口径差表须带标签对照。
